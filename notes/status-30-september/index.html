What works

The rig is the strongest part. On 30 September it ran with the TV off. hands built a track, rendered it, and ears measured it. The render path refuses to damage an existing arrangement.

Editing time inside Live also works now. The Live API cannot cut or delete time. The Edit menu can, and it moves automation along with clips. That is how HW002 became 30 seconds.

ears now reports honest numbers. True peak is a real true peak. Loudness uses the file's actual channels. A missing model now reads as missing, not as zeros.

The mastering lab is the best-calibrated tool in the system. Its 94 known-answer checks all pass. It has already found facts about the HW002 demo. The loudest moment is a breakdown hit, not the kick. There is a hole in the low mids.

This site can now take a render and stream it. The audio lives in cloud storage, not in git. Adding one is a single upload and a line of text.

What is stalled

The rungs above the meter

The plan in note 10 set four steps before the kick engineer. Calibrate the measures. Wire the critic to them. Join the critic to the knob map. Then run a kick-only loop.

Only the first step is started. The kick body measure failed its calibration by 17 to 37 percent.

Note 3 compared your kick to the corpus using that measure. It called your kick "a short, dark, sub-carrying note". Part of that reading may be the ruler. No page has revisited it yet.

The pump measure also still reads a floor near 12 dB on full mixes. That fix is designed but not built.

Taste

taste has not changed since 30 March. The judge function raises an error or returns a placeholder. The prototype has a real judge, but no tests and no packaging.

The corpus holds five verdicts that look like seed data. The listening test has three answers, all on the retired synthetic set. Note 10 estimated about 200 picks for a first model. At three a week that is fifteen months.

Scattered work

Important work sits outside GitHub. The September sweep scripts live in an untracked folder inside autodaw. So does a newer recorder with a routing retry. The Hammerspoon idle-aware backup rewrite was never committed.

All of it is on an external backup drive. None of it is on the Mac mini. The current rig was rebuilt from the March code.

Contracts between repos

The repos talk through JSON files and command lines. Two of those joins are broken. taste calls ears with a flag ears does not have. The ears schema uses field names the code does not emit. Inside ears, the rhythm step failed in March on a missing library.

So the full loop has never run end to end. hands to ears works. ears to taste does not.

Blockers, by who can clear them

Only you

  • Activate Dist COLDFIRE through Native Access, and LFOTool through Xfer. You have deferred this.
  • Picks between renders. Any engineer loop needs them to learn what you want.
  • The listening test on the real-sound set. It takes about fifteen minutes.
  • A premaster and three to five references for the mastering lab.
  • Permission grants on the Mac that agents are refused. One is the background job installer.
  • Power and lock settings, so long runs are not killed by sleep.

Technical

  • Live's API cannot export or edit time. Workarounds exist and are tested, but they are slower.
  • Enabling a control surface still needs one click in Live's settings.
  • The embedding model has no home that ears can fetch from.
  • The kick body measure needs fixing before the critic can trust it.
  • The pump measure reads a floor above about 12 dB on full mixes.

Organisational

  • Work is split across at least eight places. Some of them are not in version control.
  • Three measuring stacks exist: ears, the research measures and the mastering lab. Each is calibrated differently.
  • Two threads compete with production: the humming transcriber and autodaw's browser work.
  • No production note was published between 12 September and today. The rule says to publish each result.

Risks worth naming

An old prototype server in hands was built for listening on a phone. It has powers that are unsafe on a network. It must stay offline until it is rebuilt.

Live updates can change dialog layouts. Scripts that drive Export by screen reader need a recheck after each update.

Against the dates in note 10

Ground-truth stems were due and done on 11 September. The knob map beat its date with 16 rows on the 12th. Calibration is partly done. The kick body fails, and the pump floor is uncorrected.

The critic and the kick loop have no date met. The first overnight kick engineer was dated 16 October. Sixteen days remain and the critic is unwired. That date will slip unless work resumes now. The third note in this series says where I think the effort should go.
