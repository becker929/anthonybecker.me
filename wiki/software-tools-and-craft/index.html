Software tools and craft

Four sources on the ordinary work of shipping software.

Written by Claude Opus 5.59 November 2026, 01:25 UTC (17:25 Pacific)

These sources are about the ordinary work of shipping software. This page lists four sources, oldest first where dated.

How To Not Die By A Thousand Cuts. Or, How To Think About Software Quality.

Aditya Athalye. 20 January 2022 (updated 10 March 2023). Personal essay on software quality, with a diagram and a reading list.

The essay is an opinion piece drawn from about twenty years of the author's work. It treats quality as an organisational trait, not a testing stage. It offers an ASCII diagram, lists of scenarios and a reading list, but no data.

Bun Runtime Security Considerations: Speed vs. Safety Trade-offs

Bob, Application Security Engineer, Safeguard.sh. 11 February 2026. Vendor blog post, a security overview with a product pitch at the end.

The post is a short overview of where Bun's design helps or hurts security. It compares Bun with Node.js and Deno on install scripts, permissions and native code. It has no tests or measurements. It ends with a pitch for the vendor's scanner.

I hate packaging my software for Linux

Not stated. Undated. Project blog post, a personal account from a maintainer.

The post is a first-person complaint on the blog of the Fresh terminal editor. It lists each Linux packaging channel the author tried and what went wrong. It offers anecdotes from the project and no measurements beyond download size.

Sample Videos

Not stated (Intel IoT DevKit repository, intel-iot-devkit). Undated. GitHub repository README, a gallery of sample video clips.

The README is a table of preview animations and links to MP4 clips. File names suggest detection and recognition tasks, such as people, cars, bolts and faces. The README has no prose, so it states no purpose or licence.

Glossary

AppImage
A single-file Linux app format that runs without installation.
AUR
The Arch User Repository, where users share package build recipes for Arch Linux.
Corner-cut
A shortcut that saves time now and costs more later.
Detection
Finding and labelling objects in an image or video.
Flatpak
A Linux system for sandboxed desktop apps.
FUSE
A Linux feature that lets programs provide their own filesystems.
Inference
Running a trained model on new input to get predictions.
JavaScriptCore
The JavaScript engine from WebKit, used in Safari.
Lifecycle script
A command a package runs automatically during install.
Lockfile
A file recording the exact dependency versions an install used.
MP4
A common video file format.
Musl
A small C library that makes static Linux binaries easy to build.
OODA
Observe, orient, decide, act, a loop for responding to change.
QA
Quality assurance, the work of making sure a product meets its goals.
SBOM
A software bill of materials, a list of a product's components.
Seccomp
A Linux feature that limits which system calls a process may make.
SLA
A service level agreement, a promise about uptime or performance.
Static linking
Building a program with its libraries included so it needs none installed.
Technical debt
The future cost of shortcuts taken in building software.
Zig
A systems programming language with manual memory management.
