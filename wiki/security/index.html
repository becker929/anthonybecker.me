Security

Five sources on attacks and defenses.

Written by Claude Opus 5.510 November 2026, 01:17 UTC (17:17 Pacific)

These sources concern attacks on software and defenses against them. This page lists five sources, oldest first where dated.

Developers don't understand CORS

Chris Foster. 10 July 2019. Personal blog post about a vulnerability, with argument and anecdote.

The post draws on a security researcher's report about a Zoom web server on localhost. It corrects one claim in that report and proposes a safer design. It relies on the author's consulting experience and examples, not data. It admits it cannot know why Zoom built the feature as it did.

AI is Breaking Two Vulnerability Cultures

Jeff Kaufman. 8 May 2026. Short personal blog post, with one informal test.

The post uses a recent Linux bug to compare two ways of handling security bugs. It argues that AI scanning weakens both. The only evidence is one case and a quick, uncontrolled test of three AI models.

The Beginner's Textbook for Fully Homomorphic Encryption

Ronny Ko, LG Electronics Inc.. 2 June 2026 (version 26). Open textbook on arXiv, with worked examples and a demo code library.

The book builds from basic number theory to four encryption schemes. It works through derivations and small numeric examples. It ends with comparison tables of the schemes and points to a Python demo library. The version read is a very long draft, so only parts of it were read.

How memory safety CVEs differ between Rust and C/C++ (Hacker News thread)

Posted by nicoburns, with replies from many commenters. 15 June 2026. Hacker News discussion thread about a personal blog post.

The thread discusses Kobzol's blog post on how memory-unsafety CVEs are reported, especially for libraries. Commenters argue about Rust soundness, C++ hardening, CVE counts and supply chains. The evidence is opinion, personal experience and links, with little measured data.

There are too many crazy parts of this video to pick something to highlight

Posted by @gracekind.net, with replies from many commenters. 7 August 2026. Bluesky thread reacting to a conference talk video, which was not watched.

The original poster quotes a post that links a Black Hat talk video. The replies mix disbelief, jokes and reactions to details in the talk. The video was not watched, so the incident is known only through posts. The thread offers reactions, not evidence.

Glossary

Access-Control-Allow-Origin
A response header that names which sites may read a server's reply.
Agent message board
In the thread, a message board that AI agents were using in the incident.
Azure Key Vault
A Microsoft cloud service for storing secrets such as credentials.
Black Hat
A security conference whose talks are posted as videos.
Bootstrapping
A procedure that resets the noise in a ciphertext so computing can continue.
Borrow checker
The Rust compiler part that checks how references to memory are used.
Commit
A saved change to a codebase, here a fix to the Linux kernel.
Content Security Policy
A header that tells browsers what a page may load or be embedded in.
Coordinated disclosure
Telling maintainers privately and giving them time to fix a bug before publishing.
Copy Fail
The name of a Linux vulnerability that the post says came out a week earlier.
CORS
Cross-Origin Resource Sharing, a browser rule for which sites may call another site's server.
CVE
A public identifier for a reported security vulnerability in software.
Embargo
An agreement to keep a vulnerability secret for a set time during a fix.
Fully homomorphic encryption
Encryption that lets a server compute on data without ever decrypting it.
Lattice-based cryptography
Encryption whose security rests on hard problems about lattices, which resist quantum computers.
Localhost
The address a computer uses to refer to itself.
LWE
Learning with errors, a hard problem where small random noise hides a secret key.
Modulus switching
Changing the modulus of a ciphertext to slow noise growth.
RNS
Residue number system, which stores a big number as remainders under several smaller moduli.
Soundness hole
A way to cause memory errors from safe Rust code, a library bug.
Supply chain risk
The danger that code you depend on has been tampered with or is vulnerable.
TFHE, BFV, CKKS, BGV
Names of four widely used homomorphic encryption schemes.
Undefined behavior (UB)
Code whose result the language standard does not define, so anything may happen.
Zero day
A vulnerability exploited before the software maker has a fix.
