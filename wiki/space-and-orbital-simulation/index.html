Why is the crescent Moon sometimes lit on the bottom?

The StarChild Team, NASA Goddard Space Flight Center. March 2002. Government educational Q&A page for young readers.

This is a short Q&A from NASA's StarChild site for young readers. It explains the Moon's path across the sky by season and the observer's latitude. It adds a section on folklore about the wet moon and dry moon. It gives explanation and diagrams, with no measurements.

All asteroids in Solar System, visualized

Posted by d_silin, with replies from many commenters. 10 October 2024. Hacker News thread about an open-source asteroid visualization.

This thread discusses a demo that plots asteroid orbits from catalog data. The poster says it is a data visualization, not an exact simulation. Commenters trade explanations about gaps in the belt, detection bias and scale. The evidence is the poster's account and commenters' reasoning, with no measurements.

Show HN: Python Simulator of David Deutsch's "Constructor Theory of Time"

Posted by SandroG, with replies from many commenters. 18 May 2025. Hacker News Show HN thread about a physics code library.

The poster presents a Python library that turns a constructor theory paper into runnable code. Replies ask what it is for, request examples and question how physical the code is. One commenter doubts the theory's standing in physics. The thread has no experiments, only claims about the code and opinions.

Lox – Oxidized Astrodynamics

Helge Eichhorn and Angus Morrison (copyright holders named in the README). Undated. GitHub README for an open-source library.

This is the project README for Lox, a Rust astrodynamics library with Python bindings. It gives quick-start code, install commands and a feature list. It says the project is pre-1.0 and its API may change. The README offers no benchmarks or validation results.

Evolutionary Mission Trajectory Generator (EMTG) Open Source Release

Originating author Jacob Englander; maintained by the NASA Goddard EMTG team. Undated. GitHub README for a government open-source release.

This is the README for the open-source release of EMTG, a NASA Goddard trajectory tool. It covers dependencies, installation, a question-and-answer section and legal notices. It says the release is infrequent and support is limited. It describes the software only briefly and shows no results.

Glossary

Apoapsis
The point in an orbit that lies farthest from the body being orbited.
Astrodynamics
The study of how spacecraft and other bodies move under gravity and thrust.
Constructor
Something that can carry out a task repeatedly and keep its ability.
Constructor theory
A proposed framework that states physics in terms of which tasks are possible or impossible.
CSPICE
A NASA toolkit for computing positions of planets and spacecraft.
Ellipse
The oval shape that most orbits follow.
Ephemeris
A table giving the position of an object in the sky over time.
Integrator
A routine that advances a simulation by small time steps.
J2 perturbation
A small change in an orbit caused by Earth's bulge at the equator.
Kirkwood gap
A dip in the number of main-belt asteroids at certain orbital periods linked to Jupiter.
Latitude
How far north or south of the equator a place is.
Link budget
A tally of signal gains and losses between a transmitter and a receiver.
Morphism
In category theory, an arrow that maps one object to another.
SGP4
A standard model for predicting satellite positions from published orbit data.
SNOPT
A commercial optimization program that EMTG can use to solve for trajectories.
Sun-synchronous orbit
An orbit that passes over a place at the same local solar time each day.
Symplectic integrator
A numerical method for stepping a physical simulation forward that keeps energy errors from growing.
Task
In constructor theory, a change to a physical system that may be possible or not.
Trajectory
The path a spacecraft follows through space over time.
Waxing crescent
A thin lit sliver of the Moon that grows larger each night.
