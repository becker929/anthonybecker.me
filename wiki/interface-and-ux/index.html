Interface and UX

Eight sources on how people use interfaces.

Written by Claude Opus 5.59 November 2026, 17:53 UTC (09:53 Pacific)

These sources are about how people use interfaces, and how to design them. This page lists eight sources, oldest first where dated.

How Video Games Inspire Great UX

Scott Jenson. 1 September 2019. Personal blog essay, built on examples from well-known games.

Jenson, a long-time UX designer, retells a series of meetings with game designer Raph Koster. The essay turns Koster's book into six lenses for app design. Evidence is a set of game and software examples, plus one invented Photoshop example. No users were tested.

Ask HN: What are good high-information density UIs (screenshots, apps, sites)?

Posted by troupo, with replies from many commenters. 8 May 2025. Ask HN discussion thread, mostly lists of examples.

The thread has 530 points and a long tail of replies. Most replies are short example lists with links, plus a few debates on density. Evidence is opinion and personal experience. Some repliers built the tools they name.

Molly guard in reverse

Marcin Wichary. 12 February 2026. Short blog post on the Unsung site, mostly images.

Wichary explains the hardware term molly guard and then flips it. A reverse molly guard presses itself if the user waits. The post is a brief design observation with images. It offers no tests.

The future of UX design is not a higher-velocity version of its present

Pavel Samsonov. 31 May 2026. Newsletter essay, built from quotations and argument.

Samsonov argues that AI-driven speed only multiplies small changes. The essay leans on quotations from other writers on service design, scale and wicked problems. It offers no data. It ends by pointing to mapping methods and a new information architecture framework.

Your "File" Menu Isn't About Files

Adam Farkas. 22 August 2026. Personal blog post, a tour of 35 apps, partly satire.

The post is a list. For most of 35 Mac apps, the author gives a verdict and a new name. Five more get praise. The tone is jokey, and the author later calls it partly satire. The evidence is the author's own inspection of apps on one laptop.

Bluesky reply naming the lastchat app and its fonts

barredspirals.comint.su. 30 August 2026. Bluesky reply post.

The post answers a question about the typography in a screenshot. It names the app and two fonts. It is very short.

The Product Picnic

Pavel Samsonov. Undated. Newsletter home page, listing recent posts.

This is a landing page, not an article. It shows a tagline and six post titles with one-line summaries. The summaries lean skeptical about AI in product work. None of the posts were opened.

Laws of UX

Jon Yablonski. Undated. Reference site home page, listing named design principles.

The page is a short index, not an argument. It lists named laws and effects, each with a one-line definition. It also promotes a poster and a book. No evidence is shown on this page.

Glossary

Affordance
A visible clue about what an object or control can do.
Alegreya
A serif typeface designed for long reading.
Bottom feeding
A game term for staying at an easy level and never progressing.
Chunking
Grouping small pieces of information into meaningful larger units.
Code block
A section of text set in a fixed-width font.
Cognitive load
The mental effort needed to use something.
DAW
Digital audio workstation, software for recording and arranging music.
Doherty Threshold
The response time below which neither user nor computer waits on the other.
Double diamond
A design process model that alternates between widening and narrowing ideas.
Fidelity cascade
The progression from rough wireframes to finished production code.
Fitts's Law
The time to reach a target depends on its distance and size.
Fractal
A pattern that repeats at smaller and smaller scales.
Friction
Deliberate extra effort in an interface that slows risky actions.
Hacker News
A news and discussion site run by the startup investor Y Combinator.
Hick's Law
Choosing takes longer as the number of options grows.
Information architecture
The structure that organizes and labels information so it can be found and understood.
Information density
How much information an interface shows in a given amount of screen space.
Iosevka
A narrow monospaced typeface that people can build in custom variants.
Juicy
Game slang for lots of visual and audio effects in response to each action.
Menu bar
The row of menus across the top of a Mac screen for the active app.
Modifier key
A key such as Ctrl or Alt that changes what another key does.
Molly guard
A cover over a critical button that prevents accidental presses.
SaaS
Software sold as a subscription service.
Satire
Writing that mocks something, often by exaggeration.
SCADA
Software used to monitor and control industrial plants.
Service design
Designing the whole service and its internal processes, not just the screens a user sees.
TUI
A text-based user interface that runs in a terminal.
Wicked problem
A problem that cannot be fully specified before work on it begins.
