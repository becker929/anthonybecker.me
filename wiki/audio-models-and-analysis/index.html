Audio models and analysis

Seven sources on analyzing, compressing and generating sound.

Written by Claude Opus 5.59 November 2026, 00:55 UTC (16:55 Pacific)

These sources ask how sound can be analyzed, compressed or generated. Two are Hacker News threads, and they were read without their linked articles. This page lists seven sources, oldest first where dated.

Synthesizing Music from JSON

Dominic Szablewski (PhobosLab). 6 January 2025. Personal blog post introducing an open source synth and editor, with code.

The post explains how pl_synth works and how the author made the JavaScript version faster. It shows code for the synthesis loop, the editor and song storage. Evidence is shown code and timing figures for the author's own project.

WildFX: A DAW-Powered Pipeline for In-the-Wild Audio FX Graph Modeling

Qihui Yang, Taylor Berg-Kirkpatrick, Julian McAuley and Zachary Novack, UC San Diego. 17 July 2025. arXiv preprint presenting a dataset-generation tool with one experiment.

WildFX is a Docker pipeline that drives the REAPER DAW with real plugins. The paper tests it by training a model to estimate effect graphs. The authors say the results fall short of the earlier work.

Neural audio codecs: how to get audio into LLMs

Posted by karimf, with replies from many commenters. 21 October 2025. Hacker News discussion thread about an explainer post from Kyutai.

The thread discusses a Kyutai explainer on turning audio into tokens for language models. The explainer's author, posting as vvolhejn, replies often. Commenters debate MP3 as a tokenizer and why voice models seem to miss pitch.

How the cochlea computes (2024)

Posted by izhak, with replies from many commenters. 30 October 2025. Hacker News discussion thread about a blog article on hearing.

The thread discusses a 2024 blog article on whether the ear does a Fourier transform. Most replies argue over definitions and whether the title is clickbait. Others add facts about phase, neurons and speech.

How To Train a Generative Kick Drum Model on Your Old Linux Desktop With 6GB of VRAM

Not stated (published on the personal site zhinit.dev, GitHub user zhinit). 16 July 2026. Personal blog post describing a hobby project, with audio samples.

The post walks through three models trained to generate kick drums. It covers data cleaning, training choices, deployment and problems that came up. Evidence is the author's own project and a few audio samples.

Resonate

Alexandre R.J. François. Undated. Researcher's project page for an algorithm, with papers and audio demos.

The page explains how banks of simple resonators compute spectra sample by sample. It lists two conference papers, a talk and code packages. Evidence is formulas, spectrogram comparisons and audio demos, not a benchmark table.

Toward a Sparse Interpretable Audio Codec

John Vinyard. Undated (the citation block gives the year 2025). Research-style blog write-up of a proof-of-concept model, with audio examples.

The page proposes encoding audio as a set of events with times, not fixed frames. It gives model details, a streaming method and five audio examples. The page itself says reconstruction quality is not yet good enough.

Glossary

Adversarial loss
A training signal from a second model that tries to spot fake outputs.
Basilar membrane
The strip inside the cochlea whose different parts vibrate at different frequencies.
Blind estimation
Working out how audio was processed from the result alone.
Classifier-free guidance
A trick that exaggerates the pull of the text keywords during generation.
Cochlea
The fluid-filled spiral organ in the inner ear that senses sound.
Codec
Software that compresses audio for storage and rebuilds it later.
Constant-Q transform
A spectrum method whose frequency bins are spaced like musical notes.
DAW
Digital audio workstation, the software used to record and edit music.
Demo scene
A hobby community that makes tiny programs with striking graphics and music.
Diffusion model
A model that learns to remove noise step by step.
Directed acyclic graph
A set of nodes and one-way links with no loops.
Docker
A tool that packages software and its dependencies into an isolated container.
Envelope
A shape describing how a sound's volume rises and falls over time.
EWMA
An exponentially weighted moving average, which weights recent values more than old ones.
FFT
The fast Fourier transform, the standard way to compute a spectrum.
Formant
A band of frequencies that a vocal tract strengthens when making vowels.
Fourier transform
A math tool that splits a signal into pure sine waves of different frequencies.
Gabor transform
A Fourier-style analysis that uses a smooth window to keep timing information.
Impulse response
The recorded way a room or object rings after a short sound.
Latent space
A compressed representation in which each point stands for a possible sound.
LFO
A low frequency oscillator, used to wobble another sound setting.
Lookup table
A precomputed list of values read instead of calculating each time.
Mel spectrogram
A picture of sound energy over time, with frequencies spaced like human hearing.
Moshi
A speech-based language model built by Kyutai.
Neural audio codec
A learned model that compresses audio into a small stream of numbers or tokens.
Opus
A common audio codec for voice calls and streaming.
Oscillator
A generator of a repeating wave such as a sine or square.
Phase
Where a wave is in its cycle at a given moment.
Phasor
A rotating complex number that tracks the phase of a wave.
Plugin
An add-on program that applies an effect or makes sound inside a DAW.
REAPER
A commercial DAW that can be scripted.
Residual vector quantization
Coding each slice of audio with several small dictionaries, one correcting the previous.
Resonator
A simple filter that responds strongly to input near one chosen frequency.
Short-time Fourier transform
Fourier analysis applied to short slices of a signal in turn.
Sidechain
A routing where one track's signal controls an effect on another track.
Sparse
Using only a few active elements, with the rest left empty.
Spectrogram
A picture of how sound energy is spread over frequency and time.
T-SNE
A method that flattens many-dimensional data into a plot while keeping neighbors close.
Token
A discrete unit that a language model reads and writes.
Tracker
A music editor where notes are entered in rows of patterns.
U-Net
A neural network shaped like a U, used here to remove noise.
VAE
A variational autoencoder, a model that compresses data into a small code and rebuilds it.
Vocoder
A model that turns a spectrogram back into an audio waveform.
VRAM
The memory on a graphics card.
WASM
WebAssembly, a compact code format that browsers run at near native speed.
Wavelet transform
A way to analyze a signal using short wave shapes of varying width.
