Glossary

Aseprite
A program for drawing pixel art and sprites.
Bluesky
A social network where people publish short public posts.
Computational functionalism
The view that a mind is defined by the computations it performs.
Epiphenomenalism
The view that mental states have no causal effect on physical events.
Fabula Ultima
A tabletop role-playing game.
Fast fashion
Cheap clothing made quickly to follow trends.
Folly
A pointless but amusing project, a word the post uses for British follies.
Foundry Virtual Tabletop
Software for running tabletop role-playing games online.
Gift link
A link that lets non-subscribers read a paywalled article.
Hello World program
The first simple program many beginners write, which prints the words "Hello World".
Hieroglyphs
Pictorial writing used in ancient Egypt.
Mid-tier
Clothing priced between cheap fast fashion and expensive luxury.
Phenomenology
The felt, first-person character of experience.
Special effects
Visual tricks added to a film.
Steam
An online store and library for PC games.
Stop motion
A technique that films posed objects one frame at a time.
Supervenient
Depending on lower-level facts, so that no lower-level change means no change.
Temple Maker 64
A game for building and sharing Zelda-like dungeons.
Tiled
A map editor for building tile-based game levels.
Zelda-like
A game in the style of the Legend of Zelda series.
