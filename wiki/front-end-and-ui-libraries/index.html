Front-end and UI libraries

Eight libraries and frameworks for building interfaces.

Written by Claude Opus 5.510 November 2026, 01:17 UTC (17:17 Pacific)

These sources are libraries and frameworks for building interfaces. Most are project pages. This page lists eight sources, oldest first where dated.

Hyperflask – Full stack Flask and Htmx framework

Posted by emixam, with replies from many commenters. 16 October 2025. Hacker News discussion thread on a framework launch.

The thread is mostly opinion and personal experience from developers. Much of it drifts from the framework to Flask versus FastAPI, htmx state, and ORMs. The author answers several questions directly.

Jelly UI — Soft Web Components

bmson.com (named on the page). Undated. Project landing page for a UI component library.

The page text is short. It names the features, shows a three-line usage snippet and links to an API reference. The interactive showcase did not appear in the text and was not viewed.

Cosmograph · GitHub

cosmograph-org (GitHub organization). Undated. GitHub organization profile page.

The page is a short organization profile with a one-paragraph README and a repository list. It says little about how the tools work. It is a pointer to the main site.

Foldkit | TypeScript Frontend Framework Built on Effect

Devin Jameson (copyright holder named in the page footer). Undated. Project landing page for a software framework.

The page is the framework's own pitch. It explains the architecture and shows two test styles. It also says who should not use it. It offers no benchmarks or user results.

GitHub - onlook-dev/onlook: The Cursor for Designers • An Open-Source Visual Vibecoding Editor

onlook-dev (the Onlook team). Undated. GitHub project README for an open-source tool.

The README describes the editor, a feature checklist, a seven-step architecture and the tech stack. It also promotes a hosted product and a hiring call. The evidence is a description and screenshots, with no tests or measurements.

Remeda

Not stated (the Remeda project's documentation site). Undated. Project documentation landing page.

The page is the library's own pitch, with short code comparisons against Lodash and Ramda. The comparisons are of typing and style, not speed. It states a test-coverage figure but shows no data.

GitHub - rxi/microui: A tiny immediate-mode UI library

Not stated in the README (repository owner is rxi). Undated. GitHub project README for a small C library.

The README is brief. It lists features, one code example, usage links and a contribution policy. It has no benchmarks.

srcl

Not stated (the page invites visitors to hire its studio). Undated. Component library showcase page.

The page is one long catalog. Each component has a description and a live example. It is a showcase of the library's own work. It makes few claims beyond what each component is.

Glossary

AGENTS.md
A file of written instructions for AI coding agents working in a project.
ANSI C
A standard, older version of the C programming language that compiles almost anywhere.
AS/400
An IBM business server line whose text menus the page imitates.
Command
In Foldkit, a value describing a side effect that the runtime carries out.
Currying
Turning a function of several inputs into one that takes its inputs in steps.
Data-first and data-last
Whether the data being processed is the first or last argument of a call.
DOM
The browser's live tree of page elements that a script can change.
Effect
A TypeScript library for writing programs whose side effects and errors are tracked in types.
Embedding
A list of numbers that a machine learning model uses to represent an item.
FastAPI
A Python web framework built around async code and API endpoints.
Flask
A lightweight Python web framework.
Htmx
A small JavaScript library that lets HTML elements fetch page content from a server.
Immediate-mode UI
A style where code describes the interface afresh every frame.
Lazy evaluation
Putting off work until its result is actually needed.
Llms.txt
A plain text file listing a site's pages for AI models.
Locality of behavior
The idea that code for a behavior should sit next to the thing it affects.
MCP
A standard way for AI agents to call tools and read data.
Network graph
A diagram of items as dots joined by lines.
Next.js
A web framework built on React.
ORM
Object-relational mapper, a library that turns database rows into program objects.
Pipe
A helper that passes a value through a series of functions in order.
RTL
Right-to-left text direction, as used in Arabic and Hebrew.
Tailwind
A CSS toolkit where styling is written as short class names on elements.
The Elm Architecture
A design where one model, one message type and one update function drive the app.
WCAG AA
A common level of the web accessibility guidelines, including minimum color contrast.
Web Components
A browser standard for defining your own reusable HTML tags.
Web container
A sandbox that runs a web app's code in the browser or a cloud box.
Widget
A small interactive component that runs inside a larger tool such as a notebook.
