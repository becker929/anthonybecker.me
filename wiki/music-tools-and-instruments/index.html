Music tools and instruments

Seven instruments, apps and courses for making music.

Written by Claude Opus 5.59 November 2026, 17:53 UTC (09:53 Pacific)

These sources are instruments, apps and courses for making music. This page lists seven sources, oldest first where dated.

Meta Segment Anything Model Audio

Posted by megaman821, with replies from many commenters. 16 December 2025. Hacker News discussion thread, 223 points.

The thread is community reaction to a Meta announcement. Its evidence is a mix of hands-on trials, secondhand reports from GitHub issues and opinion. Results are described as inconsistent, and hardware needs as high.

DIY synths database

Atarity. Updated 11 October 2026. Landing page for a curated database.

The landing page describes a curated collection of 95 DIY-friendly hardware synthesizers, all open source. The project list is not in the page HTML. Only the page text and the RSS feed of ten recent entries were read.

How I reverse engineered a commercial spatial audio effect

Posted by epestr, with replies from many commenters. 11 October 2026. Hacker News discussion thread, 134 points.

The poster who wrote the blog post also answers most replies. The thread splits between technical interest and strong dislike of the sound. It also gathers alternative tools, hardware advice and personal audio tastes.

Eigendrum - draw a shape and hear it as a real drum

Basel Ashraf. Undated. Interactive web tool with a built-in explanation.

The page is a working instrument plus a long explanation of the physics behind it. The developer states how the sound is computed and how the solver is checked. The audio itself was not heard for this summary.

Music Finetunes | ElevenLabs Documentation

ElevenLabs documentation. Undated. Vendor product documentation page.

The page is product documentation, not an evaluation. It covers intended users, upload rules and limits, and tips for datasets and prompts. Its copyright rules are stated in strong terms.

GitHub - leolabs/ableton-js: Control Ableton Live with Node.js

Not stated in the README text (repository owner leolabs). Undated. Open source project README.

The README covers setup, example code, the message protocol and a few findings about Live. It states that the package is a work in progress. It also carries a sponsored note for the author's own product.

ossia/score: ossia score, an interactive sequencer for the intermedia arts

Not stated. Undated. Open source project README.

The README is mostly a feature list, install notes, build badges and contribution advice. Its claims are the project's own. It shows a screenshot, which was not viewed.

Glossary

AppImage
A Linux program file that runs without being installed.
Clone
A new build that copies the behaviour of an older instrument.
Copyright screening
An automatic check that uploaded audio is not someone else's protected music.
DMX
A standard signal for controlling stage lights.
Earwax
An ffmpeg audio filter that adds a headphone-friendly stereo effect.
Eigenvalue problem
A maths problem whose solutions give a drum's pitches and vibration patterns.
Enterprise plan
A higher-priced business tier with extra features and contract terms.
ETag
A fingerprint of data that lets a client skip downloading unchanged values.
Faust
A programming language for writing sound processing.
Finetune
A copy of an AI model trained a little further on a user's own examples.
Finite element method
A way to solve shape problems by splitting the shape into many small triangles.
HMAC-SHA256
A way to prove a password is known without sending the password itself.
HRTF
A model of how head and ears change sound arriving from a given direction.
Impulse response
A recording of how a room or filter reacts to a brief sound.
ISF shaders
Small GPU programs that generate or alter video, in the Interactive Shader Format.
Kac drums
Two differently shaped drums that have exactly the same set of frequencies.
Linear, time-invariant
Describes a system whose behaviour is predictable and does not change over time.
MIDI Remote Script
A Python script that runs inside Ableton Live to connect controllers and other tools.
Mode
One standing-wave pattern in which a drumhead can vibrate at a single frequency.
Nodal line
A line on the drumhead that stays still while a mode sounds.
Open source
Designs or code that anyone may read, use and modify under a public licence.
OSC
Open Sound Control, a network message format used by music and show software.
Rayleigh damping
A loss model in which higher frequencies fade faster than lower ones.
Source separation
Splitting a mixed recording into the sounds that made it up.
Spatial audio
Processing that makes sound seem to come from places around the listener.
Stem
A separate recorded layer of a song, such as vocals or drums.
Underconstrained
Having too little information to give one single correct answer.
VRAM
Memory on a graphics card, which large models need in quantity.
WebSocket
A web connection that stays open so both sides can send messages at any time.
Win rate
The share of comparisons in which one system beat another.
