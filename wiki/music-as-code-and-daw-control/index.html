Music as code and DAW control

Five sources on making music by typing or by driving music software.

Written by Claude Opus 5.59 November 2026, 17:53 UTC (09:53 Pacific)

These sources are about making music by typing, or by driving music software with programs. Most are launch threads and project pages. This page lists five sources, oldest first where dated.

Themes here: Art through code (5), Saying it exactly (1), Invented worlds (1), Handing over control (1), Given away (1).

Show HN: I built a synthesizer based on 3D physics

Posted by humbledrone, with replies from many commenters. 2 May 2025. Hacker News thread, a Show HN launch of a commercial product.

The thread is a Show HN launch by the developer, followed by many replies. The developer answers technical questions about GPU audio, determinism and latency. Commenters add their own test reports and criticism of the product page. The evidence is anecdote and developer testimony.

Radium Music Editor

Posted by ofalkaed, with replies from many commenters. 8 July 2025. Hacker News thread about a tracker-style music editor.

The thread discusses Radium, a tracker-style editor. Commenters explain trackers to newcomers and compare them to Reaper, Ableton Live and FL Studio. Several report crashes or limits. The evidence is personal experience.

Show HN: Hallucinate – Massively Multiplayer Online Rave

Posted by stagas, with replies from many commenters. 28 May 2026. Hacker News thread, a Show HN launch of a browser world.

The thread is a Show HN launch followed by feedback from many commenters. The developer answers questions in the thread and ships small fixes while it runs. Much of the discussion drifts to the history of raves. The evidence is developer testimony and user reports.

Logic Pro MCP Server for Claude, Cursor, and AI Agents

MongLong0214 (GitHub account name; the README names no person). Undated. Open-source GitHub README for a software tool.

The README describes a macOS server exposing Logic Pro to AI clients through MCP. Its distinctive feature is a contract that labels each result confirmed, uncertain or failed. It also lists its own limits at length. The evidence is self-reported counts, commands and a demo video.

Getting Started (Strudel documentation)

Not stated. Undated. Documentation welcome page for an interactive tutorial.

This is a short welcome page, not the tutorial itself. It says what Strudel is, lists uses, and shows one long code example. It offers no evidence beyond the example.

Glossary

Accessibility API
A macOS interface that lets one program read and click another program's windows.
Ad-hoc signed
Signed without an Apple developer certificate, so macOS treats each build as new.
Buffer size
How many audio samples the computer processes at once; larger sizes add delay.
CLAP
An open plugin format for audio software.
CoreMIDI
Apple's system service for sending MIDI between apps and devices.
DAW
A digital audio workstation, the main program for recording and arranging music.
Dead reckoning
Predicting where something is from its last known motion.
Deterministic
Giving the same output every time from the same input.
GPU
The graphics chip, here used to run audio calculations.
JUCE
A common C++ framework for building audio plugins.
Live coding
Writing and changing code while the music plays.
MCP
Model Context Protocol, a standard for giving AI models tools and data.
MIDI
A standard for sending notes and controls between music devices.
NPC
A non-player character controlled by the program.
OSC
Open Sound Control, a network protocol for music software.
Physical modeling
Making sound by simulating how real objects vibrate.
Piano roll
A grid view for editing notes on a timeline.
REPL
An interactive editor that runs code as you type.
Scheme
A small programming language in the Lisp family.
Sequencer
A tool that triggers notes in a set order.
Shader
A small program that runs on the graphics chip to draw pixels.
SysEx
A MIDI message type that carries device-specific data.
Three.js
A popular JavaScript library for 3D graphics in the browser.
Tidal Cycles
A pattern language for making music with code, written in Haskell.
Tracker
Music software where notes are typed into scrolling vertical columns of numbers and symbols.
Vibe coding
Building software mostly by prompting an AI model and not reading the code.
Warez
Pirated software.
