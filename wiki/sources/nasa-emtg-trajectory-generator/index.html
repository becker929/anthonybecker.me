What it is

The file names Jacob Englander as originating author. NASA Goddard's EMTG team maintains it. It lists version 9.02 and the license. It explains how to get and build the software.

What it says

  • The release contains all source code and documentation for EMTG, with some third-party code bundled.
  • All dependencies are free software except the SNOPT optimizer, which works best at version 7.6.
  • Build guides cover Windows and Linux.
  • The GUI is limited because of limited staffing, which the file calls an opportunity.
  • The software may be used commercially and in teaching, but no executable is provided.

What evidence it gives

The README offers instructions, a FAQ and legal text. It describes no trajectories, results or tests.

Interests and limits

The page is the maintainers' own description. The tool's performance was not examined. The linked user guides and build documents were not read. The README states the software comes with no warranty.
