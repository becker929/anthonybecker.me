What it is

The page is the entry point of the Strudel documentation. It introduces Strudel as a way to write music with code in a browser. It points readers to the workshop and the online editor.

What it says

  • The page says Strudel is an official JavaScript port of Tidal Cycles.
  • The page says no prior JavaScript or Tidal Cycles knowledge is needed.
  • The page lists live coding, algorithmic composition, teaching and sequencing over MIDI or OSC.

What evidence it gives

The page offers a single code example credited to eddyflux. The example is not a recording. The page makes no tested claims.

Interests and limits

The page is project documentation, so it presents Strudel favorably. The workshop pages that follow were not read. The code example was not run and no sound was heard.
