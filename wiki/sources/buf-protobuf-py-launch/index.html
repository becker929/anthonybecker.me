What it is

Buf publishes tools around Protocol Buffers and wrote this launch post. It describes protobuf-py, which keeps messages as plain Python objects. An optional Rust accelerator speeds parsing. The post ends with install steps using uv.

What it says

  • Buf says protobuf-py passes every binary and JSON case in the conformance suite.
  • Buf says Google's Python package carries an API shaped by C++ and Java.
  • Messages in protobuf-py are plain Python objects with __slots__, per the post.
  • The post says betterproto is proto3-only, with no proto2, editions, extensions or custom options.
  • In Buf's benchmark, an end-to-end home page build ran at 1.06x the speed of upb.
  • Buf says the library has no runtime dependencies and runs on pure Python 3.10+.

What evidence it gives

The post gives a throughput table against upb on one workload. In isolation, parse ran at 0.22x and serialize at 0.60x of upb. It says an empty failure list is checked into the repository. The benchmark harness is public.

Interests and limits

Buf wrote the library and sells related products, including a schema registry. The benchmark is one text-heavy social-media workload chosen by Buf. Claims about Google's package and betterproto are unverified here. The repository, harness and conformance results were not opened or run.
