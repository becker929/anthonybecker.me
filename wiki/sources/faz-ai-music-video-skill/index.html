What it is

The repository owner faz.ms publishes a skill: written instructions and scripts for Claude Code. The skill guides an agent through beat alignment, Google Flow generation and local compositing. It is meant to be copied into a skills folder.

What it says

  • The README describes a Claude Code skill for music videos timed to a song.
  • SKILL.md describes a pipeline from a song to a generated video of a few minutes.
  • SKILL.md says to do cheap, reviewable work first and costly work only on approved material.
  • SKILL.md tells the agent to ask before spending credits. Images are free and video is not.
  • SKILL.md allows only one browser worker in the credit-spending tool at a time.
  • SKILL.md says to compute exact things like timings and sign text in code.

What evidence it gives

The page offers instructions, a list of scripts, references and examples folders, and two commits. SKILL.md gives a stage-by-stage plan and working rules. No finished video, test or measurement was read.

Interests and limits

Only the README and SKILL.md were read, not the references, scripts or examples folders. The skill depends on paid tools, including Google Flow and video models. The commit messages credit Claude Opus 5.5 as co-author. There is no evidence here that the pipeline produces good videos. The page shows no date, only relative ages.
