What it is

The project's docs introduce Worktrunk. They explain why worktrees help when running several coding agents at once.

What it says

  • Worktrunk is a CLI that makes Git worktrees as easy as branches.
  • It addresses worktrees by branch name and computes paths from a template.
  • The page says it is possible to manage 5-10+ agents in parallel.
  • One command, wt switch -c -x claude feat, creates a worktree and starts Claude.
  • The merge command squashes, rebases, merges and cleans up in one step.
  • It lists hooks, LLM-written commit messages, CI status and shared build caches as extra features.

What evidence it gives

The page shows command comparisons and sample terminal output. It cites no benchmarks or user studies.

Interests and limits

The page is the maker's own documentation, so it only argues for the tool. Linked command pages and guides were not read. Demo videos were not viewed.
