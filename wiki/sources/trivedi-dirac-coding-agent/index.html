What it is

Max Trivedi of Dirac Delta Labs built Dirac. The README describes its features, installation and a harness comparison. Dirac is a fork of Cline.

What it says

  • The README says Dirac edits by stable line anchors, not search-and-replace blocks. This cuts edit size and retries.
  • It says Dirac inspects and edits code through syntax trees. One call can rename hundreds of references.
  • It says a cheaper Utility model can handle compaction and permission checks. A case study found over 80% lower cost.
  • It describes Goal mode. Dirac works toward an objective for hours or days and pauses when it needs input.
  • The README says Dirac completed all 8 tasks at an average cost of $0.18. Others averaged $0.38 to $0.73.
  • It admits a Cline bug slightly under-reported cache-read costs. This affected the Dirac and Cline results.

What evidence it gives

The main evidence is a table of eight refactoring tasks from public repositories. Opencode also scored 8 of 8. Every agent used the same model, and each cell links to a diff. The README also uses screenshots, which were not viewed.

Interests and limits

The authors built Dirac and ran the comparison, with a sponsor named on the page. Eight tasks and one model is a small sample. The linked task methodology and blog posts were not read. Cost figures include a known undercount for Dirac and Cline.
