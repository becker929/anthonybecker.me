What it is

The page belongs to the Polytoken documentation site. An unnamed maintainer writes release notes, often in the first person. They cover providers, permissions, sessions, compaction and the terminal interface.

What it says

  • Version 0.9.7 expands the model catalog. Kimi K3.1 Pro and Mistral Large 4 are added.
  • The notes say catalog updates are mostly experimental, and support for most providers is best-effort.
  • Version 0.9.5 skips the rest of a tool batch when a state-changing tool fails.
  • Version 0.8.9 adds model groups. A group moves to the next listed model when a provider fails.
  • Version 0.8.0 adds tool_flow, running several tool calls in one call. The notes call it experimental.
  • Version 0.5.0 adds crash reporting, on by default. Reports exclude logs, prompts and files.
  • Version 0.8.11 says Polytoken dropped Sentry. Feedback submissions were lost between September 4 and that release.

What evidence it gives

The page lists dated-by-version changes only. It offers no benchmarks, tests or user data. Claims about fixes and speed-ups are the maintainer's own statements.

Interests and limits

The author is the tool's maintainer and gives no name or release dates. Nothing here shows whether a listed fix works. The page gives no overview of what Polytoken is. It describes one product's history, not agent tools in general.
