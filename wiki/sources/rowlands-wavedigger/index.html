What it is

The README for WaveDigger, an open source app by the repository owner. It sets out to find approximate physical locations from wireless identifiers.

What it says

  • WaveDigger finds Wi-Fi access points by BSSID and cell towers by network parameters.
  • The app accepts three BSSID formats and also looks up LTE and 5G NR towers.
  • The README says it queries Apple's real WLOC API, built on the apple-corelocation-experiments research.
  • It notes that not every BSSID is in Apple's database, especially new or private ones.
  • A hosted version exists, and the code uses the AGPL v3.0 licence.

What evidence it gives

The README is documentation only. It lists features, architecture and install steps. It reports no benchmarks or accuracy measurements.

Interests and limits

The README is the author's own description of the project. Accuracy of returned locations is not tested. Setup was not run here. Privacy implications of such lookups are not discussed in the README.
