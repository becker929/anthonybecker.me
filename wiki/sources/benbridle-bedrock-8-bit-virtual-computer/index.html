What it is

The page presents Bedrock as an 8-bit virtual computer for graphical programs. It lists documentation and implementations.

What it says

  • The page describes Bedrock as 8-bit, with a 16-bit address space and 8-bit native words.
  • The page says Bedrock exists first and foremost as a specification.
  • The page says a confident programmer can write a core emulator in a day.
  • The page says porting to new hardware takes between a day and a week.
  • Programs can currently be written only in Bedrock assembly, and a high-level language is planned.
  • Programs currently run on Windows, Linux, the web and the Nintendo DS.
  • The page says Bedrock began as a fork of Uxn and Varvara, then diverged.

What evidence it gives

The page lists working emulators, five demo programs with file sizes, and a stated origin. It gives no measurements of speed or porting effort.

Interests and limits

The project's own page describes it, so claims about ease and longevity are the maker's. The demos were not run. Linked docs and specification were not read.
