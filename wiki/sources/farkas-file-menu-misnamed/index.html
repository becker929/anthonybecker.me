What it is

Adam Farkas wrote this on a personal site. It targets apps that title the first menu "File" yet handle few files. It proposes names that match what the menu items do.

What it says

  • The post asks why the first Mac app menu is called File. Its items rarely concern files.
  • The author goes through the File menus of 35 apps on a MacBook. Thirty get a short verdict and a suggested name, and five are honorable mentions.
  • Suggested names vary by app, such as Event for Calendar and Message for Mail. Chrome, Firefox and Safari all get Browse.
  • For Find My, Maps, Reeder and Weather, the author suggests deleting the menu. For Dictionary, the author suggests removing it as other Apple apps do.
  • The post quotes Apple Developer guidance. Apps without file types can rename or drop the menu.
  • Finder, Terminal, Photoshop, TextEdit and Visual Studio Code are listed as good examples.
  • After Hacker News comments, the author added that the post was partly satire.

What evidence it gives

The author opened the menus of 35 installed apps and judged each by eye. The post gives one short comment per app. It adds an Apple Developer quote and a short list of apps that fit.

Interests and limits

The post is one person's opinion, and the author says it was partly satire. Only apps on one MacBook were checked. The post has no user testing and no data on whether other names help. Suggested names are the author's taste.
