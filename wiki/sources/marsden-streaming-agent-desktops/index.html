What it is

Luke Marsden and Chris Sterry describe Helix Code. It runs agents in Linux desktop containers with GPUs. The post explains why they chose Moonlight and Wolf. It also covers where the protocol's single-user design causes trouble.

What it says

  • Helix streams agent desktops using Wolf, a C++ server for the Moonlight protocol.
  • Moonlight assumes one private session per client, but Helix needs many users on one agent.
  • In apps mode, the Helix API pretends to be a Moonlight client.
  • Wolf's new lobbies mode lets many clients share one screen. Helix is migrating to it.
  • Lobbies mode still has bugs, such as wrong mouse scaling and corrupted video.
  • The post gives typical Moonlight latency as 50 to 100 ms, working over 4G.
  • Helix still runs apps mode for development because it is stable.

What evidence it gives

The post gives an account of the architecture and the bugs found. It gives one latency range with no method. It shows no benchmark against RDP or VNC. A closing line claims a demo video streams 4K better than RDP or VNC.

Interests and limits

Helix is promoting a private beta of its own product. The latency range is unmeasured in the text. The embedded 4K demo video was not viewed, only the page text. The post is a snapshot of work in progress from the date given.
