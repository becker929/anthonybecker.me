What it is

Azhenley posted the link to the paper, and a few users replied. The thread names libraries and discusses a flaw reported by an implementer. It is a short exchange rather than a review.

What it says

  • Commenter inhumantsar says the im Rust crate provides an RRB-based immutable vector.
  • Commenter erichocean points to Bifurcan, a Java library with RRB-trees.
  • Commenter ashton314 says RRB-trees are the native vector type of Rhombus.
  • Commenter xeubie says many slices and concats leave RRB-trees with gaps and too deep.
  • Xeubie says the Clojure rrb-vector maintainer reached the same conclusion and switched to B-trees.
  • Commenter bjoli says many implementations skip strict rebalancing to speed up concatenation.
  • Bjoli proposes a radix tree that degrades to a b+tree and says work has started.

What evidence it gives

The thread offers first-hand implementation experience and links. It has no measurements or code.

Interests and limits

The linked PDF was not opened for this page, so the thread is described alone. The flaw report comes from one implementer and was not checked. The thread is small.
