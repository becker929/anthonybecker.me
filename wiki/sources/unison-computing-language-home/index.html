What it is

The page introduces Unison as a statically typed functional language. It links to docs, community, libraries, a roadmap and a managed cloud platform.

What it says

  • The page says Unison stores code in a database, removing builds and allowing instant renames.
  • The page says code is referenced by hash, which removes a class of dependency conflicts.
  • Code samples show hello world, a distributed map-reduce with Remote, and an HTTP request.

What evidence it gives

The page offers three short code examples and feature claims. It has no benchmarks, case studies or comparisons.

Interests and limits

Only the home page text was read; linked docs and the demo were not opened. The makers wrote the page, and their company also runs a cloud platform. The page is undated. Feature claims are untested here.
