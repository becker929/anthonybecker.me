What it is

The page names no author and is a translation of a note in French. It starts from slides by Gabriel Scherer on object-oriented and functional symmetry.

What it says

  • Guarded methods put constraints on the receiver for single methods, callable only when they hold.
  • OCaml has no syntax for guarded methods, but a type equality witness can encode them.
  • The witness is a type eq with one constructor, Refl, buildable only for equal types.
  • A flatten method takes a witness that the element type is a list.
  • A sum method takes a witness that the element type is int.
  • Calling sum on a list of lists fails to compile with a type error.
  • Static methods and Kotlin-style extension methods are alternatives, but both are defined outside the class.

What evidence it gives

The note gives OCaml code for an object list class with flatten and sum methods. It shows assertions and the compiler error for a wrong call. It reports no wider tests.
