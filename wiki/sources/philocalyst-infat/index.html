What it is

The README describes Infat, a command line tool for macOS. It lists and sets which app opens a file extension or URL scheme.

What it says

  • A notice says Infat is now managed on Tangled, and GitHub is a mirror.
  • Infat can show or set the default app for an extension or URL scheme.
  • Associations can be loaded from a TOML config with extensions, schemes and types tables.
  • The README says openers cascade, so a format's own rule beats a broader type.
  • Infat installs with Homebrew, or can be built from source with the just command runner.

What evidence it gives

The README gives command examples and a sample config. It shows no output from a real run and no test results.

Interests and limits

The maintainer wrote the README, and the tone is promotional. The README admits a lack of test cases. Nothing was run for this page.
