What it is

The README is written by the project, which lists pico.sh as sponsor. It describes zmx as session persistence without windows or splits.

What it says

  • zmx keeps terminal shell sessions alive so users can attach and detach without killing them.
  • Several clients can join one session, and reattaching restores earlier state and output.
  • It can send commands to a session without attaching, and print scrollback as plain text.
  • It works on Mac and Linux, and can be used as a Zig package.
  • The README says zmx does not provide windows, tabs or splits.

What evidence it gives

The README gives a feature list and build commands. It links two demo videos and a post titled You might not need tmux. None were viewed.
