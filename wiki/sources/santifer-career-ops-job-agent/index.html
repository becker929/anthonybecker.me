What it is

Santiago Fernández de Valderrama Aparicio wrote this README for a personal job search tool. It filters postings, tailors CVs and tracks applications. The user decides every step.

What it says

  • Creator santifer reports 740 listings evaluated, 68 applications, 12 interviews and 1 offer.
  • It checks that a posting is still live before any other work.
  • It scores roles against the CV and may advise skipping, which the user can override.
  • It drafts application answers but never submits them or sends email.
  • The README says there is no telemetry; the CV goes only to the chosen provider.
  • It runs inside AI coding command-line tools such as Claude Code, Codex and OpenCode.
  • The README admits that a code check cannot yet judge every rewording of a CV.

What evidence it gives

The README gives the creator's own search numbers, a demo recording and a feature list. It links press coverage and public hired stories. It offers no independent test of how well the scoring predicts outcomes.

Interests and limits

The creator promotes the project and calls the numbers from the creator's own search. The README lists a sponsor and a waitlist for a web version. Only the README was read, not the code or linked docs. Images and the demo recording were not viewed. The README's own disclaimer says AI models can behave unpredictably and may hallucinate skills.
