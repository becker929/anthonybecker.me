What it is

The Cognition Team wrote this launch post for Windsurf Codemaps. It describes how the feature works and why Cognition built it. It sets out to persuade engineers to use AI that builds understanding.

What it says

  • Cognition announces Windsurf Codemaps, AI-annotated structured maps of code for a given task.
  • Per the post, a user enters a task or picks a suggestion.
  • The post says maps link nested code groups to exact lines, with expandable trace guides.
  • The post says a map can be cited in a Cascade prompt as context.
  • Cognition argues that engineers must understand AI-written code to be accountable for it.
  • The post says new engineers take 3 to 9 months to fully ramp.
  • Cognition says it has not yet benchmarked whether maps improve its own agents.

What evidence it gives

The post offers a feature walkthrough and the team's own use of the tool. It cites three outside estimates on onboarding and maintenance. It gives no benchmark of its own, and says so.

Interests and limits

Cognition sells Windsurf and Devin, so the post promotes its own product. The claim of being first of its kind is the company's own. No measured results are given for Codemaps. The outside figures are linked in the post but were not checked here.
