What it is

Brittany Ellich is a software engineer at GitHub. The post is a how-to guide for delegating small tasks to coding agents. It aims to persuade engineers to try the workflow.

What it says

  • Ellich calls the method Agentic Software Development: delegating well-scoped tasks to coding agents.
  • Ellich's process is three steps: If you know it, write it, ship it.
  • Ellich delegates only tasks where the exact solution is already known.
  • Ellich wants each issue doable by a newcomer, without extra context.
  • Ellich reports merging 4 to 6 tech debt PRs a week alongside feature work.
  • Ellich handles only 3 to 4 agent tasks at a time.
  • Ellich says a cheap, quick preview environment is critical to the workflow.

What evidence it gives

The post offers the author's own experience over several months. It gives example issues and per-request price figures. It has no measurements or data.

Interests and limits

The author works at GitHub, which makes the Copilot coding agent used here. The results come from one engineer on one team. The claim that AI tools will cost more later is the author's guess. The blog page is a stub. The full text came from the linked Offprint copy, dated 23 November 2025.
