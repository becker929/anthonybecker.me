What it is

The README introduces microui and shows how its calls look in code. It also states the license and the project's stance on contributions.

What it says

  • The README describes microui as a tiny, portable immediate-mode UI library in ANSI C.
  • It says the library is about 1100 lines and works within a fixed memory region.
  • It does no drawing itself, so any renderer that draws rectangles and text works.
  • The author says pull requests adding features will likely not be merged.

What evidence it gives

The README gives a feature list and a short C example. It links to usage documentation and a browser demo. The images were not viewed.
