What it is

This is the home page of the A2UI documentation site. It introduces a protocol for agents to describe user interfaces. It points to specs, demos, guides and a visual composer tool.

What it says

  • A2UI lets agents send declarative UI descriptions that clients draw with native widgets.
  • The site says agents can only use components from an approved catalog.
  • Version 1.0 is current and adds function calls in both directions.
  • The site says the flat, streaming JSON lets models build interfaces step by step.
  • It lists renderers for Angular, Flutter, Lit and Markdown.
  • The site says A2UI is Apache 2.0 licensed and was created by Google.

What evidence it gives

The page offers description, a version table, a six-step flow and links. It embeds two demo videos, which were not viewed. It gives no benchmarks or user results.

Interests and limits

Google created A2UI, and the claims of safety and ease are the project's own. Nothing on the page tests them. Only the home page was read; linked specs, guides and demo videos were not opened.
