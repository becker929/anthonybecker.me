What it is

The Rust project generates this page from the source of the core crate. It describes core as dependency-free and minimal. It then indexes everything the crate offers.

What it says

  • The page calls core the dependency-free foundation of the standard library.
  • Core links to no upstream libraries, no system libraries and no libc.
  • Core has no knowledge of heap allocation, concurrency or I/O, because those need platform integration.
  • Core assumes memcpy, memmove, memset, memcmp, bcmp and strlen exist, from libc or compiler-builtins.
  • Consumers must define a panic handler that never returns, marked with #[panic_handler].
  • The page warns these requirements are not currently stable.

What evidence it gives

It is reference documentation: a short overview and long lists of one-line descriptions. It has no benchmarks or examples.

Interests and limits

The page says the listed requirements are not currently considered stable. Item entries are one-line summaries, and the linked item pages were not read.
