What it is

James Daniel Whitford is an engineer at Ritza and writes for Tech Stackups. The post explains how the team built Agent Draw on tldraw. It sets out to show how an agent can read and draw on a canvas.

What it says

  • A user drags a rectangle and speaks, and the agent draws inside it.
  • It builds on tldraw's official agent starter kit, which runs on a Cloudflare Worker.
  • Recorded audio goes to a Worker route that forwards it to Mistral's Voxtral model.
  • Captures join a first-in first-out queue, and one consumer draws them in turn.
  • Removing two actions, review and setMyView, roughly halved the model calls per capture.
  • A custom prompt section tells the model to draw labelled diagrams, not paste the transcript.
  • Opus 4.8 sketched cricket with the pen tool, while Haiku 4.5 used plain shapes.

What evidence it gives

The post shows code excerpts from a public repo and links a live demo. It reports a small model comparison using two requests per model. It reports that two removed actions roughly halved model calls, without giving timings.

Interests and limits

The author works at Ritza, and the post promotes the team's own demo and repo. The model comparison uses two requests with no scoring, so it is anecdotal. Screenshots and the demo were not viewed. The tldraw SDK needs a licence key for public use.
