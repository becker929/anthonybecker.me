What it is

The poster, misbahsy, shared a weekend project on Hacker News. It is a server that lets AI assistants call video and audio editing functions. The post links a GitHub repo and a Smithery listing.

What it says

  • The poster calls the project a starter kit for video and audio tools.
  • The poster says Claude 3.7 and Gemini 2.5 Pro were used to scaffold the repo.
  • The server lists tools for trimming, format conversion, subtitles, overlays, speed changes and silence removal.
  • The poster says all the tools live in one server.py file, with a pytest suite.

What evidence it gives

The post gives a list of tool names with one-line descriptions. It claims a full test suite but shows no results or demo.

Interests and limits

The poster built and promotes the project. The post is short, and the linked repo and Smithery page were not opened. The thread has 2 points and no comments, so nobody tested the claims in public.
