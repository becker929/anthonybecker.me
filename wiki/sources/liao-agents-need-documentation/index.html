What it is

Kevin Liao argues that memory plugins solve the wrong problem. The post says agents should read and maintain documentation instead. The post introduces Liao's own tool, Operator Memory, as the alternative.

What it says

  • Liao describes memory plugins as RAG. Snippets go into a vector database, and top matches are injected.
  • It lists five problems: similarity ranking, lost context, stale truth, unknown unknowns and unauditable stores.
  • Documents should cover what code cannot show, such as requirements, decisions and constraints.
  • A lean catalog loads at session start, and the agent opens the rest when needed.
  • The working agent should write documents while it has full context, not a background agent.
  • Facts should be rewritten when they change, never appended.

What evidence it gives

The post reports no controlled tests. Figures such as 1,000 snippets and 80k tokens of exploration are illustrations or estimates. Liao describes about a year of personal use, starting in August 2025.

Interests and limits

Liao builds Operator Memory, so the case is not neutral. Liao says it is free and open source. Liao admits sometimes having to step in to create, rewrite or trim documents. Liao also says most agents will not split or consolidate documents unprompted.
