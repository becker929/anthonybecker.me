What it is

xenharmlib is a Python library for music theory across many harmonic systems. It covers Western and non-Western systems, microtonal tunings and post-tonal set theory. It is aimed at composers and researchers who know basic Python.

What it says

  • Supported temperaments include just intonation, quarter-comma meantone, Bohlen-Pierce and Wendy Carlos's Gamma.
  • An example builds a chord in 31 equal divisions of the octave.
  • It can approximate arbitrary frequencies to notes, reporting the error, for spectralist composition.
  • It can suggest modulations between keys.
  • It aims to explore harmonic relations, not to be a sequencer or synthesizer.

What evidence it gives

The evidence is the working code in its examples. This page has read the documentation and has not run the library.

Interests and limits

It requires Python and is released under the GPL version 3. Parts of its stated scope, such as score rendering, remain on its roadmap.
