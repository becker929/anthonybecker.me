What it is

The file is an overview written by the project for its own tool. It describes the Loom as a multi-engine orchestration layer. It names the engines it can drive and the features around them.

What it says

  • The document says no single model or agent design is best for every task.
  • The Loom is a shared layer, and model clients are interchangeable shuttles.
  • A web interface over a Tailscale tailnet lets users control agents from a phone.
  • Progressive draft saving keeps a run going if the browser tab closes.
  • A permission hook halts agent tool calls and asks the user in the browser.
  • One database schema lets users switch models mid-conversation. A tree view shows every branch.
