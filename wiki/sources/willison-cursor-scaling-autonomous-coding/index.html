What it is

Simon Willison runs a weblog on AI tools. This link post quotes Cursor's report and adds the author's own test of the repository.

What it says

  • Cursor ran hundreds of concurrent agents on one project, writing over a million lines.
  • Planners and sub-planners made tasks, workers did them, and a judge agent ended each cycle.
  • Cursor chose a from-scratch web browser, and the agents ran close to a week.
  • The first announcement drew skepticism because CI failed and build instructions were missing.
  • The author built it on macOS and got a working window with obvious rendering glitches.
  • The author found the quality surprising but does not expect competition with Chrome soon.

What evidence it gives

The author built and ran the repository and shows screenshots of two pages. The agent figures come from Cursor's own report, which the post quotes. No test results are given.

Interests and limits

Cursor sells coding tools, so the report has an interest in the result. The author only tried two pages and did not run conformance tests. The post is short and links to Cursor for detail. A later update points to a video interview that was not read.
