What it is

Unreal Labs, a startup, wrote this post to announce Unreal Agent. It explains why the team built its own harness and how tool calls work. It then reports results against Codex and Pi.

What it says

  • Unreal Agent runs tool calls asynchronously, so the model need not manage waits.
  • The post claims up to 40% savings against Codex and up to 20% against Pi.
  • Each tool call logs an in-progress record at once, and the result is added later.
  • Users can steer the agent without waiting for tool calls to finish.
  • The authors say CLI-oriented SDKs carry assumptions that fit production poorly.
  • The authors prefer sandbox and environment limits to hook-based security approvals.
  • On Terminal-Bench 4.0 both agents passed 57.9%, at dollar totals of 1428 and 2350.

What evidence it gives

The post gives four benchmark tables with pass rate, cost, tokens and turns. Most runs link to Harbor records. The tests use one model and mostly coding benchmarks. The post calls pass-rate differences marginal and credits them to benchmark variance.

Interests and limits

Unreal Labs sells agent services and asks readers to contact the company. Only one model was tested, GPT-6 Astra xhigh. The Codex Terminal-Bench figure comes from a leaderboard, not a matched run. The animation was not viewed.
