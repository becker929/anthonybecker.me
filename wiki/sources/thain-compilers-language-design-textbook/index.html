What it is

Douglas Thain, a professor at Notre Dame, publishes the textbook for the compilers course online. The page offers chapter PDFs and a print edition. It targets undergraduates who know C, data structures and computer architecture.

What it says

  • The page says the book is free, with chapter PDFs open to download.
  • Readers build a simple compiler from a C-like language to x86 or ARM assembly.
  • Chapters run from scanning through code generation to optimization. A sample course project follows.

What evidence it gives

The page gives no evidence beyond its own description. It lists chapters, an appendix on a sample project and a code repository of examples.

Interests and limits
