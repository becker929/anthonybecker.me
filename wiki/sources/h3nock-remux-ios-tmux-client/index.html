What it is

The README is written by the project. It presents Remux as a phone-first way to use tmux. It points to a TestFlight beta and gives build steps.

What it says

  • Remux is a native iOS client for remote tmux, built on Ghostty's terminal core.
  • Users swipe between windows and pick panes from a bottom sheet with live previews.
  • It has a saved-command palette with starter sets for shell, Claude Code and Codex.
  • It offers on-device voice dictation and photo or file uploads with image markup.
  • The README says SSH goes direct, with no relay or account. Keys sit in the iOS Keychain.
  • It previews files and localhost dev servers by long-pressing paths or URLs in terminal output.

What evidence it gives

The README offers a feature list and build commands. It links a demo video that was not viewed. It shows no test results or user figures.

Interests and limits

The project is in public beta on TestFlight. Security claims such as Secure Enclave key support were not checked. The demo video was not viewed. The README is short.
