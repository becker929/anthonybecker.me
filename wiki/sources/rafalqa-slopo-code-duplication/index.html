What it is

The page is the README of the rafal-qa/slopo repository. It explains what the tool does, how to install it and how to configure it. It also explains how Claude Code and Codex skills drive it.

What it says

  • The README says Slopo uses embedding models to find differently written duplicate logic.
  • It claims agents in large codebases sometimes miss existing code and rewrite it.
  • It ranks similar-code clusters by similarity, with a boost for distant code.
  • It has two modes: review of recent Git changes, and analysis of the whole codebase.
  • Skills for Claude Code and Codex let a coding agent triage the reports.
  • The README says the tool is for experienced developers and is not a magic fixer.
  • It says simple tools are better for exact copies, being faster, more mature and deterministic.

What evidence it gives

The README offers description, setup steps and a list of settings. It links a benchmark article and example reports from real projects, which were not opened. It also links demo videos, which were not viewed.

Interests and limits

The tool's author also wrote the linked benchmark, which the README relies on. The README admits the tool can report much similar code that is not a duplicate. Claims about missed duplicates and lower cost come with no figures. The linked benchmark, example reports and demo videos were not opened.
