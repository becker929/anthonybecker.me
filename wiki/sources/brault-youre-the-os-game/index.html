What it is

Pier-Luc Brault is named as the copyright holder. The README describes a game where the player is the operating system. It gives setup steps, an automation option and the asset licenses.

What it says

  • The README says the player manages processes, memory and I/O events as the OS.
  • It says if processes idle too long, the user gets impatient and reboots.
  • It says the game runs in a browser, on itch.io, or as a desktop app.
  • It says the desktop version exposes an API for automated scripts.
  • It says the project needs Python 3.14 and pipenv. The main branch can be unstable.
  • It says pull requests are welcome for open issues labeled bug or help wanted. Other pull requests are likely to be closed.

What evidence it gives

The README offers a description, a screenshot link and commands. It gives no playtest data. The licensing section names GPL version 3 and lists the sources of art and fonts.

Interests and limits

The game was not played, and the screenshot was not viewed. The README describes the game only in a few lines. It says nothing about difficulty or how closely the game matches a real OS.
