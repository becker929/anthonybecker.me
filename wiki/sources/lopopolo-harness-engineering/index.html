What it is

Ryan Lopopolo writes for OpenAI about a five-month experiment. The post sets out what the team learned about designing environments for agents.

What it says

  • A team built an internal product with no manually written code. Codex wrote it all.
  • The post reports a million lines and roughly 1,500 merged pull requests.
  • A short AGENTS.md serves as a table of contents pointing to a structured docs folder.
  • Architecture is enforced mechanically, with fixed layers, one-way dependencies and custom linters.
  • Merge gates are minimal because agent output far exceeds human attention.
  • Agents copy existing patterns, so background tasks scan for drift and open cleanups.
  • The post says its end-to-end feature behavior should not be assumed to generalize.

What evidence it gives

The evidence is the team's first-hand account of one project. Figures such as pull request counts and a one-tenth time estimate come from the team. The post includes a docs layout and a layer diagram. It offers no outside measurement.

Interests and limits

OpenAI wrote the post and makes Codex. The time saving is an estimate, and there was no comparison build. The product was internal, with alpha testers. The post says it does not know how coherence holds up over years. The direct page load was blocked by a JavaScript check. This record uses a public Internet Archive copy of the page.
