What it is

What it says

  • The author says internet speed is part of the user experience.
  • The post imagines a minimal traffic mode with known, small page sizes for essential data.
  • The author offers this as a fallback if infrastructure fails during outages or congestion.
  • The post says an engineer could design five speed tiers, important data first.
  • An edit says it is a shared lane, not a walled garden.
  • The author guesses Steve Jobs would have pursued this, and admits having no proof.

What evidence it gives

The post offers analogies and argument only. The author mentions a personal Symbian SMS relay and slow-connection testing. No design, code or measurements for Thinnernet are shown.

Interests and limits
