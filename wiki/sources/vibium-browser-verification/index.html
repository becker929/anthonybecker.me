What it is

The README comes from the VibiumDev organisation on GitHub. It explains how to install Vibium and what commands it offers. It targets agents such as Claude Code, Codex and Gemini CLI.

What it says

  • The README calls Vibium the verification layer for coding agents. Agents can navigate pages, fill forms and take screenshots.
  • It says Vibium is a single binary of about 10MB with no runtime dependencies.
  • It says Vibium is built on WebDriver BiDi, not proprietary protocols controlled by large corporations.
  • It describes two skills: browser carries out tasks, and check assesses whether a claim holds.
  • The README says the run and check commands need the development build and AI configuration.
  • It lists Linux, macOS and Windows support. Chrome is the default and Firefox is also supported.

What evidence it gives

The README gives install commands, CLI examples, short code samples and an architecture diagram. It offers no benchmarks, test results or user reports.

Interests and limits

The README is the project's own description and promotes the tool. The author is not named. Nothing was run or tested. The linked guides, tutorials and the update post on Run and Check were not opened.
