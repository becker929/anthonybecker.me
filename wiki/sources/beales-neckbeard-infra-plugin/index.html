What it is

The repository owner bealesh publishes the README. The plugin reads an app repo and asks questions. It renders OpenTofu infrastructure from a catalog of tested modules.

What it says

  • The README says coding agents write plausible infrastructure code. It says they have never seen the invoice.
  • It says humans maintain a tested OpenTofu module catalog. The agent only maps answers onto it.
  • The README says a deterministic planner and renderer produce the files. Regeneration refuses to overwrite touched files.
  • It reports three check levels: V0 static, V1 plan, V2 deployment. The last two are not exercised.
  • It lists reference costs per lane. One AWS Fargate environment runs $149.35 idle and $155.91 expected per month.
  • It calls itself pre-alpha, with live deploys passed only on AWS and Azure serverless containers.
  • It reports 36 runs on three apps with and without the plugin. With it, V0 passed 9 of 9, against 0 of 9.

What evidence it gives

The README gives a cost table priced on 26 October 2026. It adds a status table of what has been exercised. It cites a benchmark of 36 runs and a findings ledger. The README says an earlier cost table was withdrawn after undercounts. It adds the plugin gave no help on two tasks outside its scope.

Interests and limits

The author built and promotes the plugin, so the benchmark is a self-test. The cost figures are usage scenarios, not measured bills. The README says they are not equal-capacity benchmarks. Linked benchmark and findings pages were not read. The README is unsigned.
