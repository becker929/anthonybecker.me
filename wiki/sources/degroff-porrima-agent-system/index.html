What it is

Asa DeGroff made Porrima and wrote the page. It presents a single-user agent framework for consumer hardware.

What it says

  • Porrima is a self-hosted agent that runs two language models in parallel.
  • A background model extracts memories, which the agent reviews in sleep cycles.
  • It manages five hot-swappable Llama.cpp servers, each with a user-chosen model.
  • The page says all data stays on the user's machine.
  • Minimum server specs include 32GB or more of GPU memory and 48GB of RAM.
  • It claims context continues indefinitely, with no hard breaks after compaction.

What evidence it gives

The page offers only feature descriptions and a hardware list. It shows no measurements or user results.

Interests and limits

The author promotes the project. No claims about quality were tested. Linked docs and the install guide were not read.
