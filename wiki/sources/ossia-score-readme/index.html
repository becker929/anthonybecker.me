What it is

The README belongs to the ossia score project. It lists the protocols, scripting languages and platforms the software supports. It also explains how to install, build and contribute.

What it says

  • ossia score is a sequencer for audio-visual artists, made for interactive shows.
  • It sequences OSC, MIDI, DMX, sound and video between multiple software and hardware.
  • Scripting and live coding are offered in JavaScript, ISF shaders, Faust, PureData or C++.
  • It supports IoT protocols such as CoAP and MQTT, plus joysticks, Wiimotes and Leapmotions.
  • The README calls it free and open source, running down to Raspberry Pi Zero 2.
  • Releases are listed for Windows, Linux via AppImage, and macOS.

What evidence it gives

The README offers a feature list and build-status badges for many platforms. It has no benchmarks, demos described in text or user studies.

Interests and limits

The README is written by the project to promote its own software. The feature list was not tested, and the software was not installed. Images and badges were not viewed. The README says little about how well any feature works.
