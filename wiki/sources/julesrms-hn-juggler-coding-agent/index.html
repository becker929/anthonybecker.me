What it is

The poster describes Juggler, an open-source desktop and web app for coding agents. The poster calls it a one-person side project in beta. The thread is the source here, not the repository.

What it says

  • The poster says each session is a Yjs CRDT tree that can branch into sub-threads.
  • The poster says almost everything, including tools and loop strategies, is a JavaScript plugin.
  • The poster says the app is AGPLv3 and the extension SDK is Apache-2.0.
  • The poster says almost none of the code was written by hand.
  • The poster says sub-threads do not inherit parent context, after a runaway recursion proved costly.
  • The poster confirms that editing earlier context breaks the provider's prompt cache.
  • The poster lists sandboxing, worktrees and skills as planned, not yet built.

What evidence it gives

The thread offers the developer's description and replies, plus early user bug reports. Commenters name a DeepSeek API error and a Linux launch problem. No benchmarks or comparisons appear.

Interests and limits

The author promotes own project and hopes to make it a full-time job. The repository and site were not opened, and no claim was tested. The author calls it a beta that has not been tested widely.
