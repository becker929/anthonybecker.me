What it is

Creston writes a software blog. The post argues from personal experience that containers have become annoying to work with. It sets out portability, microservice and adoption points.

What it says

  • Creston predicts that by the year 2030 no one will remember Kubernetes.
  • The post calls WebAssembly write-once-run-anywhere wherever a V8 engine can run.
  • The post names missing system interfaces, like file access and networking, as the brake.
  • Creston says the JVM made the same promise but cannot run in a web browser.
  • The post says one Worker calling another needs no network round trip.
  • Creston advises Python, Ruby and PHP developers to add Go or Rust.

What evidence it gives

The post offers argument, personal experience and one example. The example is Cloudflare Workers calling each other inside V8. It gives no benchmarks and no case study of a team replacing containers.

Interests and limits

The author names Cloudflare Workers as a favorite serverless model. The post is a prediction and admits WebAssembly is young and may not work yet. Nothing was tested. Costs and security tradeoffs are not weighed.
