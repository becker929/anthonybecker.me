What it is

Justin Young writes for Anthropic about problems with agents that work for hours or days. The post sets out to give a setup that bridges coding sessions.

What it says

  • Each new agent session starts with no memory of the last, which hampers long tasks.
  • Anthropic's fix is an initializer agent first, then a coding agent each session.
  • Early failures were doing too much at once, and declaring the job done early.
  • The initializer writes a JSON feature list of over 200 items, all marked failing.
  • Each session works on one feature, then commits to git and writes progress notes.
  • Claude marked features done without end-to-end tests until prompted to use browser automation.
  • The post leaves open whether one general agent or several specialized agents works better.

What evidence it gives

The evidence is internal experimentation on one task, a claude.ai clone. The post shows a feature-file format, a sample session and a failure-mode table. It reports no measured success rates.

Interests and limits

Anthropic wrote the post and makes the Claude Agent SDK it describes. Only one kind of project was tried: a full-stack web app. The post notes browser tools missed some bugs, such as native alert modals. It calls generalization to other fields a future direction.
