What it is

What it says

  • Larson defines the pattern as looping on a broad goal while a harness drives progress.
  • Larson describes a skill that checks a Linear project for an RFC and metrics.
  • Larson says the skill then updates issues and works unblocked tasks, such as pull requests.
  • Larson says the pattern exposed project-goal state the author had been keeping personal.
  • Larson says a post-release mode could catch changes in adoption or error rates.
  • Larson says the pieces compound only together: metrics access, Linear and an orchestrated harness.
