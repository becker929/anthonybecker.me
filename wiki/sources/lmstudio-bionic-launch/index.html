What it is

The LM Studio team wrote this launch post. It presents Bionic's features and says how to get started.

What it says

  • Bionic is a new, separate agent app for coding and document work with open models.
  • Models run locally or on LM Studio Secure Cloud. The post says cloud use keeps no data.
  • The post commits to Zero Data Retention and to never training on user data.
  • A voice keyboard dictates into any app, using local Voxtral transcription from Mistral AI.
  • Code projects point at a local folder and offer inline diffs and agentic code search.
  • Work projects process documents inside a sandboxed environment.
  • The post names GLM 5.2 and Kimi K2.7 Code as example open models.

What evidence it gives

The post offers feature descriptions and product screenshots. It gives no benchmarks, test results or independent checks.

Interests and limits

LM Studio makes and sells the product, and the post is promotion. The privacy and data retention commitments are the company's own statements. Cloud use needs an account with billing. Screenshots were not viewed, and the app was not tried.
