What it is

The page introduces Jelly UI and shows how to load it with one script tag. It credits its maker and asks for sponsorship.

What it says

  • The page describes Jelly UI as a dependency-free Web Components library for soft, tactile interfaces.
  • It lists 40 custom elements, one script tag, dark mode, RTL support and WCAG AA.
  • It says the library is free, MIT-licensed and built in the open by bmson.com.

What evidence it gives

The page offers a feature list and a short code snippet. The text reached did not include the component showcase or the API reference.

Interests and limits

The page is a short pitch written by the library's maker. The claims about physics, accessibility and zero dependencies were not tested. The showcase and the API reference were not read.
