What it is

Reuben Brooks built Shen-Backpressure and explains it through a multi-tenant API demo. The post shows how formal specs can gate an AI coding loop.

What it says

  • Brooks bets structural backpressure beats smarter agents for much production software.
  • Prompt rules are behavioral gates that models follow often but not reliably. Compilers and type checkers are structural gates.
  • Shen-Backpressure turns a Shen spec into guard types in Go or TypeScript using a generator.
  • In the demo, a resource-access value needs a tenant-access value and proof of ownership.
  • Each iteration runs five default gates. Failures feed into the next prompt.
  • The author claims only that specified invariants become practically impossible to bypass by accident.
  • The post concludes that production coding loops need better backpressure more than a better model.

What evidence it gives

The post shows one running demo with a curl transcript. It shows Alice refused access to another tenant. It shows a compiler error when a raw string is passed. It gives no benchmark and no comparison with a smarter model.

Interests and limits

The author built the tool and promotes it. The post tests no model-upgrade alternative. It names costs: writing the spec, and a larger trusted code base. Bypasses through reflection or careless SQL remain possible. The sixth gate is called experimental. The post says it is not a bet against better models.
