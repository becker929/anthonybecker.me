What it is

The README describes ableton-js, a library that talks to a script inside Ableton Live. The goal, as stated, is to expose Live's MIDI Remote Script functions to TypeScript.

What it says

  • Ableton.js lets Node.js, Deno or a browser control Ableton Live 11 or later.
  • Setup means copying the midi-script folder into Live's Remote Scripts folder and renaming it AbletonJS.
  • The script runs a WebSocket server on 127.0.0.1:39031 by default. An optional password uses HMAC-SHA256, but the connection stays unencrypted.
  • Commands started in the same JavaScript tick are combined into one WebSocket round-trip.
  • Property listeners send events, sometimes 20-30 times per second.
  • The author notes output_meter_level listeners seem to hang and clip slot playing_status never fires.

What evidence it gives

The README gives setup steps, example code, sample messages and two noted bugs. It reports no benchmarks and no tests of the library itself.

Interests and limits

The author advertises AbleSet, a setlist manager built with this library. The README says the package is a work in progress. No code was installed or run, and Live was not controlled.
