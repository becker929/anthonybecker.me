What it is

The page is part of the documentation for xenharmlib. It lists new features, each with a short Python example. They include prime limit tunings, interval arithmetic, sequences, interval fans and frequency approximation.

What it says

  • The notes say the core was refactored to allow tunings with multiple generator intervals.
  • The notes claim the library can now represent musical traditions worldwide, except irregular temperaments.
  • The notes show a Pythagorean chromatic scale built from five rising and six falling fifths.
  • The notes say default transposition is regular, so results can leave the scale.
  • The notes say custom regular temperaments can be built with multi-generator tunings.
  • The notes say interval arithmetic, long missing, is now included.
  • The notes say scales can now be matched to the closest notes for measured frequencies.

What evidence it gives

The page gives code samples with printed output for each feature. It offers no benchmarks, tests or comparison with other software. The outputs were not run for this page.

Interests and limits

The page comes from the library's own developer, so it promotes the library. The claim about representing the entire cosmos of musical traditions is not tested here. Examples cover a few small cases. The full changelog and linked documentation pages were not read.
