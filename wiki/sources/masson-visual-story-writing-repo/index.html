What it is

The README of the VisualStoryWriting repository. It names the project and links a demo, build steps and an arXiv paper. It lists what the visual edits do and how to run the tool.

What it says

  • The system draws a story as events and movements, and lets users edit through them.
  • Linking characters, moving one or reordering events makes the tool suggest text edits.
  • The tool relies on GPT-4o to extract story information and to suggest the edits.
  • The tool runs locally in the browser and does not store the user's key.
