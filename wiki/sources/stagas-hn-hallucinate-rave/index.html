What it is

The poster built a multiplayer browser world. Avatars dance to YouTube DJ sets, alongside computer-run characters. The code is on GitHub under an MIT license. The thread is the source here, not the site.

What it says

  • The developer says the project was vibe-coded in its entirety by an LLM.
  • The developer says custom shaders replaced Three.js because that library was too slow.
  • The developer says only key state changes are synced, so it should scale to hundreds.
  • The developer says the video is YouTube sets from Hot Situations and HÖR Berlin.
  • Commenters report abusive chat messages, and the developer says it blocks IPs by hand.
  • Several commenters report that the site went down under the traffic.

What evidence it gives

The thread offers developer replies and user reports of bugs. Commenters request features, and the developer reports adding several during the thread. One commenter posts a heat map of player movement from about five hours of data.

Interests and limits

The developer says the thread doubles as a job search. The site and repository were not opened, and the site was reported down at times. Claims about scale were not tested.
