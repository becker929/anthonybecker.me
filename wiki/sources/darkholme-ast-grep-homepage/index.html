What it is

The page is the homepage of ast-grep, also called sg. The copyright line names Herrington Darkholme. It introduces the tool and links to a guide, a reference and a playground.

What it says

  • The page calls ast-grep a fast tool for structural code search, lint and rewriting.
  • It describes the tool as syntax-aware grep and sed, working on syntax trees.
  • The page shows an example that rewrites the pattern $A && $A() to $A?.().
  • It offers a Node.js binding so programs can walk syntax trees with jQuery-like methods.
  • It claims speed from parallel Rust, support for 20+ languages, and loadable custom tree-sitter parsers.
  • It says the tool includes interactive codemods, a language server and a testing tool.

What evidence it gives

The page gives one example command and feature claims. It offers no benchmarks, comparisons or user numbers on the page itself.

Interests and limits

The page is written by the tool's own project, so every claim is promotional. Speed claims are not measured here. The linked documentation and the list of users were not read. The page is short and has no argument to assess.
