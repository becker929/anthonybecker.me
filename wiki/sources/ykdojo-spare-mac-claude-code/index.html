What it is

The author wants a separate machine for research and development tasks. The author also says containers cannot run Mac-only apps like Unity. The guide covers setup from a wiped Mac to remote control from a phone.

What it says

  • The guide turns a spare Mac into an always-on machine for Claude Code.
  • The author prefers a separate Mac because containers share the main machine.
  • Setup uses a fresh account with no Apple ID, SSH, passwordless sudo and no sleep.
  • Computer use over SSH needs a LaunchAgent keeping a tmux server in the GUI session.
  • Screen Recording and Accessibility can only be granted by a human at the machine.
  • The grants go to tmux, not claude, because tmux is the responsible process.
  • A final optional step adds Tailscale so the box is reachable from any network.

What evidence it gives

The guide offers commands, scripts and explanations of why each step is needed. It reports the author's own use. It gives no tests or comparisons.

Interests and limits

It reflects one person's setup and macOS behavior at the time. Several steps run agents with permissions skipped, and the guide notes inherent risk. The linked scripts and repo were not read. The page ends with a newsletter plug.
