What it is

The README describes kage, a Go program that clones a website into a local folder. It can also pack the copy into one file or app.

What it says

  • Kage clones a website into an offline folder and strips out every script.
  • It loads each page in headless Chrome, snapshots the result, then deletes the JavaScript.
  • The crawl is breadth-first, honors robots.txt, and can resume after an interruption.
  • A copy can be packed into a ZIM file, one executable, or a double-click app.
  • Packing is deterministic, so the same mirror always gives a byte-identical file.
  • Costs named: ZIM files lack a full-text index, and binaries weigh about 13 MiB.

What evidence it gives

The README gives commands and flags, an example using paulgraham.com, and a directory layout. It points to a demo GIF and screenshot, which were not viewed. It reports no tests or timings.
