What it is

The post is a subjective list of seven papers, sorted by date. The page names no author. It aims to start a debate. A bonus section lists near misses.

What it says

  • The author calls the list subjective and meant to start debate, not end it.
  • The seven papers run from Turing in 1936 to Brin and Page in 1998.
  • The post says Codd's relational model of tables led to SQL and relational databases.
  • It says Cook showed that Boolean satisfiability is NP-complete, giving a shared language for difficulty.
  • It says Brin and Page treated links as votes of confidence, which became PageRank.
  • Five more papers are named as near misses, including Brooks's No Silver Bullet.
  • The post concludes that foundations matter amid constant new tools.

What evidence it gives

The post gives no argument beyond short summaries of each paper. Each entry has a big idea, a note on present-day use, and links. The author says plainly that the choice is subjective.
