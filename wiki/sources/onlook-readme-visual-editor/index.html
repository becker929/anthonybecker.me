What it is

The Onlook team wrote the README. It explains what the editor does and how it works. It also says how to run or join the project.

What it says

  • The README calls Onlook an open-source visual editor for Next.js and Tailwind projects.
  • Users edit the browser DOM visually, and the changes are written back to the code.
  • It describes seven steps: a web container serves the code and an iframe shows it.
  • The team says it instruments the code to map elements to source.
  • A checklist shows done features and unchecked ones such as comments and non-Next.js support.
  • A hosted product for AI-native designers is in early access through a waitlist.
  • The code is licensed under Apache 2.0.

What evidence it gives

The README gives a feature checklist, an architecture outline and a tech stack list. It links to a demo video and to documentation. It reports no benchmarks or user studies.

Interests and limits

The README is written by the team that sells the hosted product. The images and linked demo video were not viewed. Claims about scaling to other frameworks are described as theoretical.
