What it is

Cloudflare posted the entry in its developer changelog. It announces that agents and applications can search the web through AI Gateway. It points readers to a how-to guide.

What it says

  • Web Search API is in beta and lets agents search the web for live information.
  • At launch there are three providers: Ceramic.ai, Exa and Linkup.
  • Requests go through AI Gateway and are billed at provider list price, with no markup.

What evidence it gives

The entry offers a curl example and a Worker example. It includes claims about zero data retention and bot crawling standards. It gives no benchmarks.

Interests and limits

This is a vendor announcement for its own product, and the page is short. The data retention claims come from Cloudflare and were not checked. The how-to guide it links to was not read. Neither code example was run.
