What it is

Ivan Velichko explains SSH tunnels. The tutorial helps readers remember which flag and which address order to use.

What it says

  • Local forwarding with ssh -L makes a remote service available on a local port.
  • The -L target can be any machine the SSH server can reach.
  • To reach a loopback-only port behind a bastion, the tutorial adds the -J flag.
  • With ssh -R, the gateway listens only locally unless GatewayPorts is set to yes.
  • Dynamic forwarding with ssh -D turns the SSH client into a local SOCKS proxy.
  • Using ssh -R with no destination makes the server a SOCKS proxy, from OpenSSH 7.6.
  • The mnemonic is that the left-hand side of the flag value opens a new port.
