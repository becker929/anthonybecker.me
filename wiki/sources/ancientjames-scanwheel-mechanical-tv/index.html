What it is

The README describes Scanwheel, a drum-style mechanical television. A scanning drum with pinholes shows images through LEDs. The page covers sourcing parts, printing the drum, wiring and running the code.

What it says

  • The README says Scanwheel has five windows that share one scanning drum.
  • It says each window is 9mm by 8mm and has 20 scan lines.
  • It says the Pico's PIO hardware drives the LEDs, giving high horizontal resolution.
  • It lists a stepper motor, an A4988 driver, a Pico and LEDs.
  • It says LED resistors must be matched by measuring current, within a 50mA limit.
  • It says the drum needs careful printing, because pinhole flaws show in the image.
  • It says the software runs on Micropython 1.28, with host code to stream video.

What evidence it gives

The README gives measured LED currents and matching resistor values. It names exact settings for printing, such as 100.33% scaling and Arachne walls. It points to code folders and a build video. It offers no test results for image quality.

Interests and limits

This is the builder's own project page, with no outside testing. The photos, wiring diagrams and video were not viewed, so only the text was read. It does not say how well the build works for others.
