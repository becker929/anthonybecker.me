What it is

Google publishes this page as reference documentation for developers. It teaches how to build agents that control a browser, phone or desktop. It sets out the loop, the actions and the safety features.

What it says

  • The tool lets a model see screenshots and act through clicks and keystrokes.
  • The developer's code must run the loop and send back a new screenshot each step.
  • The model returns coordinates on a normalized grid, which the client scales to the screen.
  • Browser, mobile and desktop environments are supported, each with its own action list.
  • Built-in safety policies include blocking agents from accepting legal terms on their own.
  • A response can require confirmation, and the client must then ask the user.
  • Prompt injection detection on screenshots is opt-in and off by default.

What evidence it gives

The page offers code samples, tables of actions and descriptions of fields. It gives no benchmark results or error rates. The samples use a browser driven by Playwright.

Interests and limits

This is a vendor page for its own product. It shows few weaknesses beyond a general warning. The page says the tool may contain errors and security vulnerabilities. Model names and versions reflect the page at the time it was fetched. None of the code was run. The code samples in several languages were skimmed, not read line by line.
