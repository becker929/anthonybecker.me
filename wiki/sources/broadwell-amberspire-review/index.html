What it is

Josh Broadwell reviews Amberspire for Polygon. The review describes the setting, the dice mechanics and how a city changes over time. It ends with an opinion on how long the game holds interest.

What it says

  • The city sits over a mausoleum whose central shaft serves as the town square.
  • Each cycle has four turns, three for the player and the fourth for rolling weather.
  • The review praises how a city evolves like a mini-history lesson, not just toward efficiency.
  • The reviewer says the mausoleum can feel like window dressing, perhaps from dice luck.
  • The reviewer says motivation dropped once the late-game loop became clear.
  • The review compares the game to a traditional board game, played now and then.

What evidence it gives

The review rests on the reviewer's own play. The reviewer built several cities on Windows PC, using a prerelease code from the publisher. It gives no scores, no play-time figures and no comparison data.

Interests and limits

The reviewer received a prerelease code from Bithell Games. This is one person's opinion. The reviewer allows that missing events may be bad dice luck. The saved page also holds an automatic summary block, which was ignored here.
