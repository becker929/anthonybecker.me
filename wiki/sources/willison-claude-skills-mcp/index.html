What it is

Simon Willison writes a personal weblog about AI tools. This post reacts to Anthropic's launch of Claude Skills. It explains the design and argues for it over MCP.

What it says

  • Willison says a skill is a Markdown file of instructions, with optional scripts.
  • Harnesses read a short description of each skill at session start. Each costs only a few dozen tokens.
  • The post says skills need a filesystem and command execution. That is their biggest difference from earlier attempts such as MCP.
  • Willison argues MCP uses many tokens, citing GitHub's MCP. A CLI tool or skill can replace most uses.
  • The post says skills work with other models. Willison says Codex CLI or Gemini CLI can be pointed at a skill folder.
  • Willison says the simplicity of skills is the point, compared with MCP's full protocol specification.

What evidence it gives

Willison tried Anthropic's slack-gif-creator skill once, in the Claude mobile web app. Willison calls the resulting GIF terrible. The post shows the script Claude wrote, which calls the skill's size check. The rest is argument and comparison from experience.

Interests and limits

This is one author's opinion written on launch day. The trial was a single prompt. The post gives no measurements of token use. Willison also admits an earlier wrong prediction about agents. The page shows a sponsor line, but the post itself does not promote a product.
