What it is

Nova Spivack introduces LACE, the Link Automata Computing Engine, written in Python. In ordinary cellular automata, only cells change. In LACE, a cell depends on neighbours and links, and links depend on their cells.

What it says

  • Rules can use topology, such as a cell's number of connections and its neighbours' degrees.
  • Link influence is adjustable, from purely decorative to strongly conditioning cell states.
  • Topology can shape behaviour, and behaviour can shape topology.
  • Spivack reports new gliders, oscillators and puffers under these rules.
  • An optional mode uses Taichi for GPU-accelerated runs.

What evidence it gives

The evidence is a video gallery and a public code repository. Spivack's claims about new behaviour rest on those demonstrations. The post gives no formal comparison with other rule classes.

Interests and limits

Spivack built the system and describes it enthusiastically, so the language is promotional. The claim that rules could simulate neural networks is stated as theory. This page has not run the code.
