What it is

The page is the documentation site for an open-source game engine. It explains state, moves, events, phases, turns and stages. The tutorial walks through a small game, from setup to a bot opponent.

What it says

  • The docs say boardgame.io keeps game state in two objects, G and ctx.
  • The docs say moves are functions that change G and must have no side effects.
  • The docs say a stage is like a phase but sits inside a turn.
  • The tutorial builds Tic-Tac-Toe in plain JavaScript or React, with a built-in Debug Panel.
  • The tutorial says a bot needs only a list of possible moves, and uses MCTS.

What evidence it gives

The docs offer worked code, a step-by-step tutorial and live CodeSandbox examples. They give no performance figures or user studies. They state that the bot uses 1000 iterations per move by default.

Interests and limits

The maintainers wrote the docs to promote their own framework. The tutorial says bot documentation is coming soon. Only the Concepts page and the Tutorial were read. The guides and API reference were not read. The site loads its text with a script. The text was read from the project's Markdown files on GitHub.
