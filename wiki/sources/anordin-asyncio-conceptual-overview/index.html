What it is

A learner who found asyncio hard to model wrote this guide to fill the gap. The README sets out the questions and describes each of the five linked sections.

What it says

  • The author says the official docs lack an overview of asyncio's design and architecture.
  • The guide promises to explain what happens behind the scenes when an object is awaited.
  • It promises to explain how asyncio separates I/O-bound tasks from CPU-bound ones.
  • It promises to show how to write your own asynchronous operations.
  • Part 1 covers the event loop, coroutine functions, coroutine objects, tasks and await.
  • A network example uses only non-blocking sockets and custom awaitables, besides the event loop.
  • The last section compares multiprocessing, multithreading and asyncio and says when to use each.

What evidence it gives

The README itself offers description only. The examples and analysis sit in the five linked parts.

Interests and limits

Only the README was read, not the five linked parts. The author writes as a learner and the README cites no sources itself. Nothing in the README is tested.
