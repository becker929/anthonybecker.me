What it is

This is a Show HN thread. The author mohyware posts a browser video editor called ClipJS and answers questions. Commenters try the tool and share feedback.

What it says

  • The author mohyware says no files are uploaded and all editing runs in the browser.
  • Several commenters praise the lack of sign-in and the speed of a month-old project.
  • Commenters list other browser video editors, including Omniclip and Pikimov.
  • Commenters report trimming only at the clip end, a 30 second default and slow export. The author thinks export uses only the CPU.
  • The author says storage caps at 2 GB, so large files fail.
  • A long side thread argues over whether an AI feature belongs in a video editor.
  • The author lists a default project as a to-do and wants to leave Remotion.

What evidence it gives

The thread offers first-hand user reports and the author's replies. One user reports a failed render with an Aborted error. Another says playback did not start after upload. There are no benchmarks or tests.

Interests and limits

The author built the tool and answers critics, so replies are not neutral. The editor itself was not opened for this page. The thread reflects a month-old project, so later changes are not covered.
