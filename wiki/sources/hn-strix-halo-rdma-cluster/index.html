What it is

Posted by jakogut on Hacker News, with replies from many commenters. It links a setup guide on GitHub for a two-machine AMD Strix Halo cluster. The guide sits in a repository owned by kyuz0.

What it says

  • Commenter jmyeet prices the build at two boards for $3150 each. The two 100G NICs add about $500 each.
  • Commenter jmyeet says memory bandwidth, under 300GB/s, is the limit for Strix Halo.
  • Commenter kamranjon first read the benchmarks as strong, then judged them slow against a Mac.
  • Several commenters report steep price rises for 128GB Strix Halo machines.
  • Commenter kcb says short copper direct-attach cables beat fibre on short runs.
  • Commenter erik says Thunderbolt currently seems to lack RDMA support, so latency is much higher.
  • Commenters say Apple silicon has far higher memory bandwidth than Strix Halo.

What evidence it gives

Commenters supply price figures, bandwidth numbers and links to benchmarks and videos. Most claims come from memory or personal purchases. The thread has no measurements run by the poster.

Interests and limits

The guide was not read for this page, only the discussion. Prices change fast, and the figures come from mid 2026 comments. Some commenters promote their own projects or sites. Posters sometimes contradict each other on bandwidth and cost.
