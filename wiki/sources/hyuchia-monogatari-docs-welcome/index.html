What it is

The page introduces the docs for Monogatari, a web-based visual-novel engine. It outlines the reading order and the sections of the docs.

What it says

  • The docs describe Monogatari as a free, open-source visual-novel engine that runs on the web.
  • A game is a real website, so it runs in browsers, desktop and mobile.
  • The engine reads script statements, runs a matching action, and updates the screen.
  • The docs suggest general web tutorials for tasks they do not cover.
  • Help is offered through community forums, a Discord server, Mastodon, email and GitHub.
  • The docs include a section on releasing a game to web, desktop and mobile.
