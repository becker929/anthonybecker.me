What it is

jyn writes a personal website about programming and tools. The essay takes Rich Hickey's meaning of simple as having one braid. It argues that small Unix tools are often coupled.

What it says

  • jyn was not satisfied with answering a debugging story with a call for simplicity.
  • The essay defines simple as uncoupled, following Rich Hickey's one-braid meaning.
  • jyn argues the word-frequency pipeline is small but coupled, since uniq needs sorted input.
  • The essay says the Unix idea of doing one thing is really about size.
  • jyn says Google Drive for Desktop is large yet feels simple to the user.
  • jyn says Clojure decouples data representation from type checking, unlike a Rust struct.
  • jyn answers that a program should be simple always.

What evidence it gives

The essay offers code comparisons, not measurements. It compares a Unix pipeline with Clojure, then a Rust struct with a Clojure map. It cites the author's own coverage pipeline, which grew larger but simpler after a fix.

Interests and limits

The essay is one author's argument resting on code examples. It does not test whether decoupling yields fewer bugs. The author says good taste is something not yet known how to teach. Later posts are promised but were not read.
