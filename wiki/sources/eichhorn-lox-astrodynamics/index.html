What it is

Two copyright holders are named in the file header. The README introduces the library and shows how to install and call it. It also explains the name.

What it says

  • The README describes Lox as an MPLv2-licensed Rust library with first-class Python bindings.
  • It lists features such as Keplerian elements, SGP4 propagation and TLE parsing.
  • It lists constellation design and RF link budgets among the features.
  • Its Python example designs an 800 km sun-synchronous orbit and propagates it with J2.
  • It states that Lox is pre-1.0 and the API may change between releases.
