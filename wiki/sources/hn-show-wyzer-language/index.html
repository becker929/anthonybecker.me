What it is

The poster is named v0id_isgood and describes starting Wyzer out of frustration with Rust. Many users replied with questions and critique. The poster later says the README and docs were updated.

What it says

  • The post describes Wyzer as a statically typed, compiled, resource-oriented language.
  • The post says Rust does not guard against distributed deadlocks, which choreographic programming targets.
  • Commenter jitl says the README and docs do not describe the language's unique ideas.
  • Commenter fmontesi, a researcher, explains that choreographies write send and receive as one instruction.
  • Commenter pron says garbage collectors cover many algorithms. A long dispute follows.
  • Commenter imthenitto argues Perceus allows sharing, so the one-rule pitch is really two rules.
  • The poster later says the README was updated and documentation put on the website.

What evidence it gives

The poster offers a description and a link to a small donut demo. Commenters add explanation and critique. No benchmarks or large example programs appear.

Interests and limits

The repository was not read for this page. The project is at an early stage, and the poster is promoting it. Commenters dispute whether the poster is the project's creator. A late reply from the account says someone impersonated the creator through it.
