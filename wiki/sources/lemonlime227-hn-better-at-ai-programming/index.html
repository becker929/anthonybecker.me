What it is

The user lemonlime227 is rewriting a jQuery and Django app into SvelteKit. Claude Code gives code that is not good enough to review quickly. The thread collects advice from many commenters.

What it says

  • The asker says simple prompting cannot match 90% of hand-written quality.
  • The asker wants output reviewable in 15 to 20 minutes, not 1 to 2 hours.
  • Commenter rdrd advises a small style guide and a plan file, revised rather than patched.
  • Commenter XenophileJKO disagrees and says current models need no restart, so refactors can continue inline.
  • Commenter 8cvor6j844qw_d6 says Claude Code works best on highly specific and scoped tasks.
  • Commenter bogtog recommends voice transcription to describe what is wanted in full.
  • Commenter Alan01252 suggests having the AI write tests first, using BDD.

What evidence it gives

The thread is personal workflow advice. No commenter in the part read gives measurements. Some replies disagree on details, such as restarting sessions.

Interests and limits

Commenters are self-selected and use different tools and languages. The asker's task is one migration, so advice may not transfer. Product recommendations come from users, with some possible bias. Read only the opening comments of the thread, not the later replies.
