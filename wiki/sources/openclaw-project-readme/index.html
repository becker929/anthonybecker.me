What it is

The OpenClaw project describes its assistant, which connects to many chat apps. The README gives install commands, a short architecture outline and links to documentation. It ends with governance, donors and a contributor wall.

What it says

  • OpenClaw is an open-source assistant that runs on the user's own computer.
  • State, memory and credentials live on the user's hardware. Models are swappable plugins.
  • The Gateway is the local control plane for sessions, tools, events and channels.
  • The README warns that tools run on the host unless sandboxing is configured.
  • By default OpenClaw phones home only for a daily version check. Prompts still go to the configured model provider.
  • A foundation develops the project and calls itself an independent 501(c)(3). OpenAI is listed as a donor, not an owner.

What evidence it gives

The README offers descriptions, commands and links. It contains no benchmarks, tests or user results.

Interests and limits

The project wrote this about its own software. The long contributor list at the end was skimmed, not read. The linked documentation was not read. The software was not run. Its privacy and security claims are unverified.
