What it is

The README describes a city simulation game for the RP2040 chip. It lists features, tips, how to play and credits.

What it says

  • The README calls TinyCity a SimCity-inspired game for the RP2040, in MicroPython.
  • Features include three terrains, zoning, budgets, power, crime, pollution and disasters.
  • It also lists milestones, hidden bonuses, save and load, and stadiums.
  • The README says it was heavily inspired by MicroCity for the Arduboy platform.

What evidence it gives

The README offers a feature list and tips. Its four screenshots were not viewed. The source code was not read. It gives no performance figures.
