What it is

The Rust teams publish this chapter as the front door to the book. It says what Rust aims to do and who it suits. It then explains how the book is organized.

What it says

  • The introduction says Rust gives control of low-level details without the usual hassle.
  • It claims the compiler refuses to compile code with subtle bugs, including concurrency bugs.
  • It names groups Rust suits: teams, students, companies, open source developers, and speed seekers.
  • It says zero-cost abstractions aim to make safe code fast code.
  • The book assumes readers have written code in some other language.
  • Chapters 2, 12 and 21 are project chapters; the rest teach concepts.
  • Many examples are meant not to compile, so readers learn to read compiler errors.

What evidence it gives

The chapter offers description and assertion only. It says hundreds of companies use Rust but names none, except Firefox.

Interests and limits

The Rust project describes its own language, so the framing is favorable. No comparison with other languages is made. The page notes it matches the print edition from No Starch Press.
