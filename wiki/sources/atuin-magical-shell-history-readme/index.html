What it is

The README is written by the Atuin project. It explains what Atuin replaces and how to install it. It links out to full documentation.

What it says

  • Atuin replaces shell history with a SQLite database that records extra context for each command.
  • It logs exit code, directory, hostname, session and duration, and computes usage statistics.
  • It rebinds ctrl-r and the up key to a full-screen search with filter modes.
  • It offers optional encrypted sync between machines, via a hosted or self-hosted server.
  • The README says it supports zsh, bash, fish, nushell, xonsh and PowerShell.
  • The quickstart pipes an install script to the shell, then registers, imports and syncs.
  • A note says Bash setup uses bash-preexec, which the README says has limitations.

What evidence it gives

The README offers an example search command, a demo animation and a feature list. It gives no benchmarks. The demo image was not viewed.

Interests and limits

The author runs the hosted sync server, so gains if people use it. The claim that the author could not read synced data is unverified here. The linked docs were not read. The README is a short pitch.
