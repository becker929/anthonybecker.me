What it is

Four researchers at Concordia University wrote this work-in-progress preprint. It asks where the tokens go when AI agents build software together. The authors name this field of study tokenomics.

What it says

  • Code review took an average of 59.4% of tokens across 30 tasks.
  • Input tokens averaged 53.9% of use, about twice the share of output.
  • Initial coding took 8.6% of tokens and design 2.4%.
  • The authors read the high input share as a communication tax between agents.
  • Coding was the exception, with 58% output tokens against 6.9% input.
  • The authors suggest a human checkpoint before code review to prevent costly loops.

What evidence it gives

The data are execution traces from ChatDev runs on 30 tasks. The tasks came from an existing dataset called ProgramDev. The authors logged every model call with its input, output and reasoning token counts. Python scripts then summed the counts by development stage. The paper gives per-stage percentages in a table and a chart.

Interests and limits

The authors call this preliminary, work-in-progress research. It covers one agent system, ChatDev, and one model, GPT-5. The 30 tasks may not represent other software work. Code Completion ran in only 6 tasks and Testing in 12. The mapping of ChatDev phases to stages is one of several possible. The paper counts tokens, not money, energy or code quality.
