What it says

  • The poster, a student, says Pulse is a local app for following Claude Code.
  • The poster says it shows token use and cost and lets phones approve tool calls.
  • Two commenters said Claude Code's built-in remote control already handles permission prompts.
  • Others said the built-in feature is buggy, drops connections or stopped sending Android notifications.
  • The poster said Pulse only works with sessions that are already running.
  • One commenter said per-call approval stops being read after a day or two.

What evidence it gives

The post gives a short description and a repo link. Commenters give anecdotes about the built-in remote control. No tests or usage data appear.

Interests and limits

The poster built the tool and is promoting it. The GitHub repo was not opened. Reports about the built-in feature are anecdotes and may be out of date. Pulse itself was not tested by commenters in the thread.
