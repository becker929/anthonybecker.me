What it is

Cua AI, Inc. wrote this README to introduce its tools for giving AI agents computers to use. It points readers to quickstarts for each tool.

What it says

  • Cua Spaces gives agents full desktops on a Mac, other owned computers or a cloud.
  • Cua Driver lets agents operate native apps and browsers on macOS, Windows and Linux.
  • Lume creates and manages local macOS and Linux virtual machines on Apple Silicon.
  • CUA-S1 is a family of small models for quick form decisions, released as early source.
  • Cua Bench builds computer-use tasks, evaluates agents and exports trajectories for training.
  • Spaces is free for individuals; Pro costs $18 a month and Teams $30 per seat.
  • The README lists deprecated packages and warns that cuabot has known security issues.

What evidence it gives

The README offers install commands, feature lists and links to documentation. It does not report benchmark results or tests. It shows two demo videos by link.

Interests and limits

Cua AI sells the Spaces app, so the README also works as a product page. Licenses are mixed, with some parts source-available and some MIT. Only the README was read, not the linked docs or code. The demo videos were not viewed.
