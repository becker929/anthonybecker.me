What it is

Nous Research publishes the agent under the MIT license. The README lists features and install commands for several systems. It also covers migration from other agents and a paid portal.

What it says

  • The README claims Hermes is the only agent with a built-in learning loop.
  • The loop creates skills after complex tasks and searches past sessions.
  • One gateway reaches users through Telegram, Discord, Slack, WhatsApp, Signal and the command line.
  • It offers six built-in terminal backends, including Docker, SSH and Modal.
  • The README says it can run on a $5 VPS or on serverless infrastructure.
  • It can import settings, memories and skills from OpenClaw, Claude Code, Codex CLI or Cursor.
  • Nous Portal is offered as one subscription for models and tools.

What evidence it gives

The README gives feature lists, commands and a documentation index. It reports no tests, benchmarks or user results.

Interests and limits

Nous Research builds the agent and also sells Nous Portal, so the README promotes both. The claim to be the only agent with a learning loop is unverified. The software was not run. The linked documentation was not read.
