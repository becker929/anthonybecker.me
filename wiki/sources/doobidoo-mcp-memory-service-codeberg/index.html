What it is

The page shows a Codeberg repository that is now an archive. The repository is maintained by Heinrich Krupp. It presents a self-hosted service that stores agent memories and retrieves them by meaning.

What it says

  • The README says development moved to GitHub on 5 September 2026. The Codeberg copy gets no further pushes.
  • The README says the service stores decisions and context for new sessions. It claims retrieval in 5ms.
  • The README lists a REST API with 76 endpoints. It also lists an X-Agent-ID header and a knowledge graph with typed edges.
  • The README says embeddings run locally through ONNX, so memory never leaves the user's infrastructure.
  • The README reports 80.4% overall R@5 on LongMemEval and 49.7% on LoCoMo. These come from its own scripts.
  • The README says a community review found a rival's headline score reflects its vector store. It says the advertised architecture was inactive.

What evidence it gives

The README gives three benchmark tables and commands to rerun them. It quotes four users. One is a 5-agent cluster using memory tags as a message bus. It lists a long release history. The comparison tables with competitors are the maintainers' own claims.

Interests and limits

The maintainer wrote and promotes this project, and the comparison tables favour it. Benchmarks were run by the project, not independently. The page is a snapshot of an archived copy. The linked docs, wiki and videos were not opened.
