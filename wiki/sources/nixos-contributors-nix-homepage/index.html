What it is

The page is written by the NixOS project. It introduces Nix, a package manager for Linux and macOS, and the NixOS distribution.

What it says

  • The page says Nix builds packages in isolation so they are reproducible.
  • The page describes NixOS as a Linux distribution built around Nix and Nixpkgs.
  • The page claims installing or upgrading one package cannot break others, and rollback is possible.
  • The page says the Nixpkgs collection has over 140 000 packages.

What evidence it gives

The page offers assertions about reproducibility, declarative setup and reliability. It gives a package count and current version numbers. It shows no examples, benchmarks or code.

Interests and limits

The project wrote the page to promote its own software. The claims were not tested here. Linked pages such as the manual and package search were not read. The page has no date.
