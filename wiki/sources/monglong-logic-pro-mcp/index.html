What it is

The maintainer publishes a Swift server for Logic Pro, Apple's music software. It covers transport, tracks, MIDI, mixer, plugins and project actions. The README says the current stable release was cut on 3 November 2026.

What it says

  • The README says the server drives Logic Pro through seven native macOS channels.
  • The README says every mutating operation returns confirmed, uncertain or failed, never a bare success.
  • The README says macOS permissions must be granted again after each upgrade.
  • The README says only desktop Logic Pro is qualified, with 12.3 the actively validated version.
  • The README admits that most locale labels are derived from Apple data, not measured live.
  • The README lists limits, such as unsupported standalone bounce and unimplemented marker renaming.
  • The README says the project was selected for Anthropic's Claude for Open Source program.

What evidence it gives

The README gives install steps, commands to reproduce its counts, and a sample report. It points to a demo video and release evidence in other files. It links CI and live end-to-end test records.

Interests and limits

The README is written by the maintainer, and the claims are self-reported. Only the README was read; linked docs, changelog and demo media were not opened. Nothing was installed or run.
