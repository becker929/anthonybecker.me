What it is

The article is a community-written encyclopedia entry. It defines the term and places it in the build process.

What it says

  • The article defines object code as the product of an assembler or compiler.
  • The article says object code is usually machine code or an intermediate language.
  • The article says object code may hold placeholders that a linker fills in.
  • The article says a linker links object and library files to make an executable.

What evidence it gives

The article cites four sources, including a compiler textbook and a 1959 paper. It gives no worked example.
