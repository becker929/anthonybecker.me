What it is

The page welcomes readers to REBOUND and sits under the hannorein/rebound repository. Hanno Rein is listed as the top contributor. It has a feature list, a contributor table, an AI policy and a paper list.

What it says

  • The page describes REBOUND as an N-body integrator that follows particles moving under gravity.
  • It lists IAS15 as a high accuracy integrator with adaptive time-stepping.
  • It says a Python module installs with the command pip install rebound.
  • It asks people not to submit LLM-generated issues or pull requests.
  • It points to related projects for extra physics, analytic tools and small-body integrations.
  • It asks users to cite the code in scientific publications.
  • It calls REBOUND free software under the GNU General Public License.

What evidence it gives

The page offers a feature list and a list of papers that describe the methods. It shows no benchmarks and no worked results. Evidence sits in the linked papers and examples.

Interests and limits

This is the project's own page, so it presents the software favorably. The linked documentation, examples and papers were not opened. The feature claims were not tested. The page names no single author.
