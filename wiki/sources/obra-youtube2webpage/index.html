What it is

The README describes a Perl script that builds a web page from a YouTube video. The page pairs a transcript with screenshots.

What it says

  • The script builds a page from a video's captions and screenshots.
  • It relies on yt-dlp and ffmpeg, and takes a project name and a video URL.
  • The output folder holds a page, timestamped screenshots, captions, the video and a stylesheet.

What evidence it gives

The README offers one usage example and a description of the output folder. It links to an example page, which was not opened.

Interests and limits

The README is short. It reports no testing, no speed, and no limits such as caption quality. The linked example page was not opened.
