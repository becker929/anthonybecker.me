What it is

The page is the landing page for Foldkit, a pre-1.0 frontend framework. It sets out to explain the architecture and persuade developers and teams to try it.

What it says

  • The site calls Foldkit a TypeScript frontend framework built on Effect.
  • It says one immutable model holds all state, changed only through a single update function.
  • Side effects are Commands returned from update, rather than imperative calls in handlers.
  • DevTools logs every Message, and the same data reaches AI agents over MCP.
  • Story tests check the state machine, and Scene tests drive features through the view.
  • The page lists poor fits: large React codebases, the React ecosystem, and mostly static sites.
  • It states Foldkit is pre-1.0, at v0.170.0, with 36 example apps.

What evidence it gives

The page offers argument, short code samples and an interactive demo. It says the site itself runs on Foldkit and lists example apps. It gives no benchmarks, case studies or independent reviews.

Interests and limits

The page is written for the framework to promote it. Claims such as faster building and confident testing are not measured. The page names one production app, Typing Terminal.
