What it is

The poster, rsgm, wrote a short post on running OpenCode's web server at home. Changes go through Git, a pull request and automatic deployment. Commenters discuss tools, models and similar setups.

What it says

  • The post says OpenCode runs as a web server on a VM, started by systemd.
  • The agent gets its own Git user, which cannot push to the deploy branch.
  • The author reviews and merges each pull request, and GitOps tooling then deploys it.
  • The post says AI release-note summaries cut update checks from hours to minutes.
  • The post names missing CI job logs in Forgejo as the main gap.
  • Commenters shared similar setups using Forgejo runners, systemd timers, Argo workflows and kanban boards.
  • Commenters expected local GPU content. The author said local models need big spending for agent use.

What evidence it gives

The post is one person's description of a personal setup. Time savings are stated as estimates. The thread adds many commenters' own setups and tips.

Interests and limits

The author reports own experience with no measurements or comparison with other agents. Several commenters promote their own projects. The post is short and promises a later write-up of the full setup.
