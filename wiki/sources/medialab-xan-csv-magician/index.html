What it is

The README is written by the SciencesPo médialab team. It presents xan as a fast CSV processor with its own expression language. It runs from install steps through a quick tour to a command list.

What it says

  • The README says xan is written in Rust and handles huge files.
  • It says xan began as a fork of BurntSushi's xsv but was nearly entirely rewritten.
  • It says its expression language is tailored for CSV and much faster than Python.
  • It says xan can read many formats including gzip, parquet, json, Excel and bioinformatics files.
  • The quick tour runs view, search, sort, dedup, stats and groupby on a media corpus.
  • It adds tools for lexicometry, networks, scraping and terminal charts such as histograms and scatterplots.

What evidence it gives

The README shows command transcripts with output on a 478-row corpus. It gives no benchmark figures for its speed claims. Screenshots and linked documents were not viewed.

Interests and limits

The authors are the tool's makers, so speed claims are self-reported. The linked command docs, and cookbook pages were not read in full. Screenshots were not viewed.
