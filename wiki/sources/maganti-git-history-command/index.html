What it is

Lalit Maganti describes git history, an experimental command in recent git releases. The post covers fixup, reword and split, and where they fall short of jj.

What it says

  • The command arrived in two releases: reword and split in git 2.54, fixup in 2.55.
  • Fixup folds staged changes into an old commit and moves every descendant local branch.
  • Fixup does not work with merge commits, which the post says may be a dealbreaker.
  • All three commands are atomic because they refuse any operation that could produce a conflict.
  • Reword and split never touch the index or working tree.
  • The post concedes the command is strictly less powerful than jj.

What evidence it gives

The evidence is the author's own use and descriptions of each command. The before and after commit graphs did not come through in the text. No tests or timings appear.

Interests and limits

The author is a personal blogger with no stated stake. The post tests no edge cases of its own. It notes that fixup fails with merge commits and that conflicts are refused.
