What it is

The page introduces the Asterinas community and its Rust kernel. It also introduces OSDK, a kit for building Rust kernels.

What it says

  • The page calls Asterinas an open-source community building Rust kernels with a framekernel design.
  • A framekernel keeps the OS in one address space, split into Framework and Services.
  • Only the Framework may use unsafe Rust, so kernel memory safety reduces to the Framework's.
  • The page claims all unsafe Rust is confined to ostd, and drivers are safe Rust.
  • The page shows OSDK creating, running and testing a kernel with cargo osdk commands.
  • The page claims Asterinas runs Linux applications without any modification.
  • The page says Asterinas uses the Mozilla Public License.

What evidence it gives

The page gives an architecture diagram, command examples and a unit test snippet. It offers no benchmark numbers. It points to a separate book for technical detail.

Interests and limits

The project wrote the page and promotes itself. The performance and security claims are not backed by data here. Nothing was built or run. The linked docs and book were not read.
