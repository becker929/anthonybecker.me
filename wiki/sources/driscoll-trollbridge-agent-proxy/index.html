What it is

The maintainer publishes the page to present the tool. It targets people running coding agents with few permission prompts.

What it says

  • Trollbridge is an HTTP proxy that checks an agent's outbound requests against lists.
  • Requests the lists do not cover are held for one-keystroke approval.
  • An optional LLM advisor can resolve confident cases, and unsure verdicts wait for the operator.
  • It gates the network only and leaves the file system and processes alone.
  • The page suggests pairing it with a sandbox such as an Incus VM.
  • Every decision goes to a JSONL audit log.

What evidence it gives

The page offers a terminal mock-up, a comparison table and one anecdote. The anecdote says an agent tried to post to nine review sites. All nine were held and one was approved. No tests are shown.

Interests and limits

The testimonial is attributed to the maintainer. The advisor error rate was not measured. The comparison table is the tool maker's own. Linked docs were not read.
