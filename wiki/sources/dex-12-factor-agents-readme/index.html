12-Factor Agents - Principles for building reliable LLM applications

What it is

Dex writes in the style of the 12 Factor App guide. The goal is to find principles for LLM software good enough for production customers. The README gives the argument and lists the twelve factors.

What it says

  • The README claims many products billed as AI agents are mostly deterministic code. LLM steps are added at chosen points.
  • The author says good agents are mostly just software, not a bare loop.
  • The README describes an agent as a loop. It says this approach does not work as well as wanted.
  • The author describes a common framework path. Builders reach 70-80% quality, then find that is not enough.
  • The twelve factors include owning your prompts, your context window and your control flow.
  • The author recommends adding small agent ideas to existing products over a full framework rewrite.

What evidence it gives

The README relies on the author's experience, including talks with at least 100 SaaS builders. It shows a short code sketch of an agent loop. It gives no data or benchmarks.

Interests and limits

The author works on HumanLayer, which sells related tools, and the README links its products. The claims about frameworks come from anecdote. Only the README was read, not the twelve linked factor pages. The details of each factor are therefore not described here.
