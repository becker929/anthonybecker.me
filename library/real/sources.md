# Sources

All items below are archive.org uploads except the Sonic Pi samples, which come from the
Sonic Pi GitHub repository. Every licence was re-read from each item's `/metadata/<item>`
JSON (the `licenseurl` field) at download time; the licence text quoted here is that field.

## HeatDish — "Mailbox Badger: Public Domain Drum Samples: Volume 1"
Licence: **CC Public Domain Mark 1.0** (`http://creativecommons.org/publicdomain/mark/1.0/`).
Creator: Patrick Callan. 38 files taken (kick, hat_closed, perc, impact — mostly a small
vintage Casio SA-75 drum-machine kit plus a few room/tom/cymbal hits). Public Domain Mark
carries no legal restriction, so no credit line is required by the licence; the item's own
page nonetheless credits it as "Mailbox Badger: Public Domain Drum Samples: Volume 1" by
Patrick Callan — attribute this way as a courtesy.
Source: https://archive.org/details/HeatDish

## 55kicks — "55+kicks [royalty free sample pack] @IR @voldanno"
Licence: **CC Public Domain Mark 1.0** (`https://creativecommons.org/publicdomain/mark/1.0/`).
Creator: IR / voldanno. 40 files taken, all labelled **kick**. The filenames inside this
pack are creative nicknames ("bonk_1", "!duing", "AAAAAAAAAA", "tomb_wah" …) rather than
literal "kick"/"bd" strings, but the pack's own title and description identify its entire
contents as kick drums, so every file was treated as a kick candidate (subject to the
same silence-trim / 3 s / loop-envelope checks as everything else) rather than skipped as
"ambiguous" — this is a source-level exception to the filename-keyword rule, made because
the source's own metadata unambiguously states what the files are. Public Domain Mark
requires no credit; the pack still credits "IR" and "voldanno" on its item page.
Source: https://archive.org/details/55kicks

## ejay-virtual-music-studio-samples — "Ejay Virtual Music Studio Drum Machine & Synth Samples"
Licence: **CC0 1.0** (`https://creativecommons.org/publicdomain/zero/1.0/`). Creators
listed: Empire Interactive, Tim Wright, Checkmate Solutions, Tantrum Media. 40 files taken.
This is by far the largest and most varied pack (1,500+ one-shots) and is the main source
for the scarce categories: stab (18, from files named "Stab dim/major/minor", "Piano Chord
Am/C", "String Chord Am/C", "lead stab", "jazz stabb", "drive basstab", "glokchord" …),
rumble (6, "rumblerama", "rumblerrama", "extra sub", "dirty subba", "good subber", "subby
bd"), riser (3, "sweeperfx1", "sweeping", "tech sweep") and part of hat_open ("forkout ohh",
"gizza ohh", "glasters ohh", "halcyon ohh", "half open hat", "holy open hat"), plus a batch
of impact ("crash", "acid crash", "flyby crash", "connect revcrash", "boomhit", "boombass" …
— crash/boom-named files, on the rule that "boom" and unqualified "crash" map to impact).
No credit is required under CC0, but the item's own credit is reproduced above.
Source: https://archive.org/details/ejay-virtual-music-studio-samples

## Sonic Pi samples (GitHub, not archive.org)
Licence: **CC0** (per the Sonic Pi repository's samples README, as instructed). 40 files
taken directly from `https://raw.githubusercontent.com/sonic-pi-net/sonic-pi/dev/etc/samples/`.
These filled in the pad category almost entirely (9 of 9 available `ambi_*` sustained/drone
sounds: ambi_drone, ambi_choir, ambi_piano, ambi_sauna, ambi_glass_hum, ambi_glass_rub,
ambi_haunted_hum, ambi_lunar_land, ambi_soft_buzz) plus 4 more riser (perc_swoosh,
perc_swash, ambi_swoosh, ambi_dark_woosh), several impact (perc_impact1/2, perc_door,
elec_cymbal, drum_splash_soft/hard), a few hat_closed/hat_open (drum_cymbal_closed/pedal,
drum_cymbal_open) and the rest kick (all `bd_*` bass-drum samples plus drum_heavy_kick,
drum_bass_hard/soft, elec_hollow_kick, elec_soft_kick). `drum_roll` was deliberately
excluded (it is a multi-hit roll, not a single hit). No credit required under CC0; Sonic Pi
and its samples are by Sam Aaron and contributors (https://github.com/sonic-pi-net/sonic-pi).
Source: https://github.com/sonic-pi-net/sonic-pi (raw sample files under `etc/samples/`)

# Sources considered and skipped

- **Listen01SamplePack** (archive.org, licence `CC Public Domain` — fine, licence was not
  the issue). Inspected all ~200 .wav filenames: the pack is a set of student field
  recordings (`dialog_*`, `landscape_*`, `rhythm_*`, `pitched_*`, `singlehit_*`, each
  suffixed with a contributor's name), not drum or techno one-shots — "singlehit" here
  means "one recorded event" from a sound-design exercise (a found object, a footstep, a
  vocal sound), not a kick/hat/clap/perc/stab/etc. hit. Skipped entirely: no files matched
  any of the required roles once ambiguous names were excluded, and using this content
  under drum/techno role labels would misrepresent it.
- **StemBass_20160922** ("This Party (free techno samples 130bpm)", licence CC0 — fine).
  Inspected the file list: despite the "techno samples" subtitle, the only audio in the
  item is four full-length instrument **stems** of one track (`stem bass`, `stem drums`,
  `stem keys`, `stem pella`) plus a full stereo `mix` — each ~3 minutes of continuous music,
  not single hits, and also only available as mp3/ogg (no wav). Skipped entirely: nothing
  in the item is a single-hit sound.
- **free-full-sample-pack** ("FREE Full Sample Pack", licence CC0 — fine). The entire
  payload is one 1.5 GB zip (`FREE-Full-Sample-Pack.zip`) with no per-file listing exposed
  via archive.org's metadata API (only the zip's own aggregate size). Downloading and
  unzipping 1.5 GB was not a practical use of this session's time/bandwidth budget relative
  to the marginal yield (the other eight sources already comfortably cover every role
  except the four the task flagged as naturally scarce). Skipped for practicality, not
  licence — this would be a reasonable next source to mine if more files are needed later.
